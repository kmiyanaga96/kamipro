## 結論（要約）
1. **シムは辞書式にT1を最大化**するため A(前倒し)を推奨。シム抽象値の2T総和は逆に B が上
   （87.98M > 74.27M）だが、これは目的関数の定義どおりでバグではない（[analysis §2](analysis.md)）。
2. **C5＝バースト追撃の減衰上限が過小**。較正（ヤマト/ヘカテー/テトラ 50万→100万、エレイン 30万→80万）で
   実機追撃 2.3〜2.8M に整合。**ゴールデン値 92,031,195 は変更前後で不変を実測確認** → 実装推奨。
3. テトラHELIX後上限(C1)・探索目的関数(C6候補)は据え置き・記録のみ。
