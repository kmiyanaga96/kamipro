# C3 intake — エジソン英霊武器バースト追撃 倍率特定（2〜2.5倍）

> エジソン英霊武器の**バースト追加ダメージ（追撃）倍率**を実機データで特定する probe（C3・CALIBRATION_ANALYSIS.md）。
> シム実装: 追撃 = `_decay('abi', _na() × edison_burst_extra_mult, 800000)`（アビ枠・slope0.04・上限80万固定・現状 mult=2.5暫定）。
> 逆算式（追撃>80万時）: `_na()×mult = 800000 + (追撃 − 800000)/0.04` → `mult = それ / _na()`。∴ **naB（＝_na相当）が要る**。

## 測定条件（ノイズ最小化・重要）
1. **中立属性の敵**を選ぶ（有利でない）＝**急所を消す**（急所は有利属性のみ発動＝これで急所補正が全て外れ逆算がクリーン）。
2. **被ダメカット・耐性ギミックの無い敵**（ヴァルプルギス・ロキのようなHP依存カットは避ける。普通の雑魚でよい）。
3. **バフなし**でエジソンを単独バースト（アサルト/legend/puvoir等が乗る前＝T1の早い位置が理想）。
4. **2〜3回**取得（別戦闘・別ターンでも可）。**会心なしの回**が1つでもあるとベスト（cap clampが緩く倍率感度が高い）。

## 記録項目（1サンプル＝1ブロック）
各回、同じ会心状態で以下を読む（会心の有無を必ず明記）:

```
### サンプルN
- 敵: （名前・属性＝中立か / 被ダメカットの有無）
- エジソン表示攻撃力: （任意・分かれば。naB baseline照合＝B1のgear-vs-model切り分けにも流用）
- エジソン通常攻撃（単発）: ______万  [会心: 有/無]   ← naB
- エジソンバースト本体: ______万        [会心: 有/無]
- エジソン英霊武器追撃: ______万        [会心: 有/無]
```

> ⚠ 通常攻撃・本体・追撃は**同一の会心状態**で揃えること（3つとも会心 or 3つとも非会心）。揃っていれば会心倍率が比率で相殺 or naBに内包され逆算可能。
> ※ 通常攻撃が複数段の場合は各段の値を全部書いてよい（単発naBはそこから復元する）。

## 受領後の処理（Claude Code）
naB（通常攻撃・非会心単発）と追撃実測から `mult` を逆算。2.0 / 2.5 のどちらに寄るか、サンプル間のブレ幅も評価し、CALIBRATION_ANALYSIS.md C3（investigating→fixed）と `DMG.edison_burst_extra_mult` を更新（golden再fit）。
副産物: エジソン表示攻撃力＋非会心通常攻撃があれば、シム `_na(edison)` の baseline 一致度を検証（B1のnaB絶対ギャップ＝gear vs model 切り分けの傍証）。
