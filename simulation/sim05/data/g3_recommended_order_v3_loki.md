## 4. この抽出で判明したこと（探索品質・C37 関連）

### ★ prefix 分散が **完全に空回り**している
ビーム採点の結果、**8本中6本が 1円単位で同一の 4,438,123,980**（`miti`/`divinus`/`legend`/`(空)`/`puvoir`/`absolute`）。
差が出たのは `judg`（4,437,067,774・−0.02%）と `sleur`（4,417,602,812・−0.46%）のみ。

さらに LS 後は**上位3本すべてが 4,478,236,864 に完全一致**し、**評価回数まで 285,457 で同一**。
キー列を厳密比較すると **`[miti]` と `[legend]` は完全同一**、`[divinus]` のみ相違ありだが**総ダメも評価回数も一致**。

∴ **C1（§6g）の「1円単位で同値の別解が複数存在」がロキ条件では更に極端**。宿儺では `factor` が
一致率23.7%・+3.5% と本当に別解へ導いていたが、**loki では開幕を強制しても探索がそれを吸収して同じ終点へ戻る**。
`abilCapPerTurn` が無いため手数に余裕があり、押し込まれた1手が実質無コストで吸収されるのが原因と見られる。

**実務的含意**: **loki 条件では `_selectRootPrefixes` の8本並列がほぼ無駄**（8ルート走らせて得るものが `judg`/`sleur` の
劣化情報だけ）。C37 の「探索パラメータは編成/敵を移したら再測する」の**6例目**。
⚠ ただし**探索を弱めてよいという結論にはしない**（プラトーが広いだけで、条件が変われば再び効く可能性がある）。

### 局所探索の利得
+0.904%（285,457評価・約750〜760秒/ルート）。エジソン default gear の +2.09% より小さいが、**改善幅もギア/敵依存**という
C37 の一般則に沿う（これで7例目）。⚠ **1ルート約13分**＝ロキは `maxPress 41` でエジソン(30)より LS が重い。

### 押下数が多い
**最大41回/ターン**（T9）。`abilCapPerTurn` が無いため上限で切られない。**実走の実行可能性はユーザー確認が必要**
（宿儺の19回制限と違い、時間内に41回押せるかは別問題）。

## 5. 実走時の注意
- **T1〜T4 のみ実行すれば足りる**（T4 で撃破見込み）。T5 以降は撃破後で観測不能。
- **§B（tier 実発動・バフアイコン数）の記録が C38 の解決データ**＝押し順の検証より優先度が高い。
- 逸脱（押せなかった手）は必ず記録する。シムは `_execKey` 不成立を黙って無視するため、**実機で押せない手は逸脱として残す**。
