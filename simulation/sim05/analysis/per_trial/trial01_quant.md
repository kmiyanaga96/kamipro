**★結論**: pre-trial の「**バースト本体は1発あたり ×0.73＝シムが 37% 過大**」は、

**∴ C44 は「`calib_burst` が非転移」ではなく、次の2つに分解される**:
- **(a) アリアン固有**: `arian_cap_boost` が過大 → **キャスパリーグでも宿儺でも同方向＝実体がある**。
- **(b) 宿儺固有の残り**: アリアン補正後もなお宿儺で ×0.77 が残るなら、それは
  **鬼神障壁 or def 20 or `final_dmg`（A7）**の側の問題であって `calib_burst` ではない。
  ⚠ **本走はこの (b) を測っていない**（敵が違う）＝**G4.9（宿儺での最終検証）へ持ち越し**。

⚠ **`calib_burst` の値をここで決めてはいけない**。configA 1.46 / configC 1.66 の 13% 食い違い（C44）に加えて、
本走は **cath_palug の def=10 が placeholder** という未確定量を含む（§2 の警告）。
def が 1 だけ違えば全成分が一律に動く＝**「本体が合っている」も def の偶然でありうる**。
**ただし §4 の「追加/本体 の比」と §5 の「キャラ間比」は def に対して不変**（共通因子で割れる）＝**そこは信用してよい**。

## 6. ★ 新規に検出した2つの構造的乖離（起票 C47 / C48）

### 6.1 C47 — シムはアリアンの「①バースト効果 追加ダメージ」と「②1アシ追撃」を**同じ値**で出している

`gamedata/js/characters.js:547-549`:

```js
const fu = sim._decay('abi', base*DMG.arian_followup_mult, DMG.arian_followup_cap);
sim.dmg += fu;  // ①バースト効果 追加ダメージ
sim.dmg += fu;  // ②1アシ 追撃(別枠2重)
```

**1回の `_decay` の結果を2回加算している**＝①と②が定義上つねに同値。実機は:

| | 実機/hit | シム/hit | 比 |
|---|---|---|---|
| ① 追加ダメージ | **10,490,213** | 1,360,134 | ×7.71 |
| ② 1アシ追撃 | **1,836,666** | 1,360,134 | ×1.35 |

**実機では ① が ② の 5.71倍**。∴ 同値モデルは構造的に誤り。
**②（追撃）だけを見ればシムは ×1.35 でほぼ合っている**＝壊れているのは①だけ。
①を「他キャラと同じバースト追加ダメージ枠」として扱えば §4 の比（アリアン実機 0.587）に素直に乗る。

⚠ pre-trial はこれを「A1 の①②同値2本 解釈の反証」として C40 の一部に書いていたが、
**該当コードの所在まで特定したのは本走が初めて**なので、独立した Cx として起票する（C40 の修正と同時に入る）。

### 6.2 C48 — judg ph2（通常攻撃）を シムは **1ヒット**、実機は **三段攻撃＝3ヒット**で出している

`gamedata/js/characters.js:373` は `sim.dmg += sim._decay('na', ...)` の**1回加算**。
実機 trial01 は press#16 / #28 とも **3値**（2,753,452 + 2,352,622 + 2,465,658 ／ 2,766,880 + 2,677,905 + 2,553,340）。

| 見方 | 実機 | シム | 比 |
|---|---|---|---|
| **1ヒット**あたり | 2,594,976 | 2,248,389 | **×1.15** |
| **1発動**あたり（実機3hit） | 7,784,929 | 2,248,389 | **×3.46** |

∴ **`calib_na` の当たり外れ以前に、ヒット数が 1/3 しか無い**。
pre-trial が「judg ph2 は1ヒットあたり ×0.99＝`calib_na=1.835` は転移」と結論したのは**1ヒット基準の読み**であり、
**発動あたりでは ×2.96 不足していた**（同じ表の「hit 6 vs 2」がそれ）。
本走ではその1ヒット基準ですら **×1.15**＝**キャスパリーグでは `calib_na` も 15% 不足**している。

⚠ **これは C46（攻撃フェイズ）・C24（1ヒット+10）と同じ「通常攻撃のヒット多重度」の話**＝3件は同じ根から出ている。
