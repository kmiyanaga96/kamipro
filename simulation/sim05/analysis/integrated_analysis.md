## 1. 結論（5行）

1. **C40（バースト追加ダメージの式）は確定的に生き残った**。**障壁もアビ上限も無いキャスパリーグ**で、
   4キャラすべて**実機1ヒットがシムの pre-decay raw を超える**＝**cap/slope/ギア上限をどう動かしても届かない**。
   pre-trial（宿儺）・M1（エジソン×configA）に続き**3環境目**＝**敵横断・編成横断で確定**。
2. **C44（バースト本体の過大）は「宿儺での見かけ」を多く含んでいた**。キャスパリーグでは
   **アリアン以外の3キャラが ×1.05（ほぼ一致）**、**アリアンだけ ×0.83**。
   ∴ **`calib_burst` 全体の非転移ではなく、`arian_cap_boost` のキャラ固有過大**が実体。
3. **C42 は素の環境で確定した**: 実機は同ターンに **`alone` 3回 / `legend` 3回**押している（シム上限はどちらも 2）。
4. **新しい構造的誤りを2つ検出**＝**C47**（シムがアリアンの①追加ダメージと②追撃を**同一値**で出している）／
   **C48**（judg ph2 の通常攻撃を**1ヒット**でモデル化しているが実機は**三段攻撃＝3ヒット**）。
5. **C41 / C45 / DOT / ストリークは本走で1つも取れていない**（T1#41 で撃破＝ターン終了に到達せず）
   ＝**M4 は省略できない**。

## 3. ★ C44 の再定義 ── 「`calib_burst` 非転移」から「アリアン固有 ＋ 宿儺固有」へ

trial01 の押下別比（同一押下＝バフ完全同一＝交絡ゼロ・n=11）:

| キャラ | 実機/シム 本体比 |
|---|---|
| ヘカテー | 1.085（CV 10.5%・n=3） |
| テトラ | 0.973（CV 3.3%・n=2） |
| エレイン | 1.077（CV 0.5%・n=2） |
| **アリアン** | **0.831**（CV 8.2%・n=4） |
| **アリアン以外** | **1.051** |

**この結果は、pre-trial が「同一 FB 内のキャラ間比」から独立に出していた結論と一致する**
（pre-trial: アリアン シム ×2.01/2.10/2.17 vs 実機 ×1.47/1.47/1.24 → `arian_cap_boost` +100% → ≈+30〜40%）。
**別の敵・別の測り方で同じ結論に到達した＝交絡ゼロの独立再現。**

∴ C44 を次のように分解する:

| 分解 | 内容 | 状態 |
|---|---|---|
| **C44(a) アリアン固有** | `arian_cap_boost`（バースト特別減衰）+100% が過大。2環境・2手法で再現 | **確定に近い**（値の決定は M3 の FB 走で最終確認） |
| **C44(b) 宿儺固有の残り** | (a) を当てても宿儺で残る過大は、**鬼神障壁 / def 20 / `final_dmg`（A7）**の側 | ⏳ **G4.9**（最終検証）へ |
| ~~C44(c) `calib_burst` 2.07 の非転移~~ | **キャスパリーグで本体が合った以上、全キャラ共通の非転移としては支持されない** | **要撤回** |

⚠ **ただし全面的な安心はできない**: `cath_palug.def=10` は **placeholder**（`gamedata/js/enemies.js`）。
シムでは `damage ∝ 1/enemy_def` が**全成分に一律**に掛かる（`src/app.js:188`）ので、
def が違えば「本体が合っている」も偶然でありうる。
**def に対して不変なのは「成分どうしの比」と「キャラ間比」だけ**＝上表と §2 の相対パターンは信用してよいが、
**`calib_burst` の値そのものを本走から決めてはいけない**。

## 4. `calib_na` の扱いを訂正する

pre-trial は「judg ph2 の1ヒットが ×0.99 ＝ `calib_na=1.835` は転移している」と結論し、
CLAUDE.md 開発ルール §5 の**肯定側の実例**として引用されている。**これは2点で弱い**:

1. **ヒット多重度が違う**（**C48**）。実機の judg ph2 は**三段攻撃＝3ヒット**、シムは**1回の加算**。
   「1ヒット ×0.99」は**シムの1加算を実機1ヒットと見た比**であって、**発動あたりでは ×2.96 不足**していた。
2. **キャスパリーグでは1ヒット基準ですら ×1.15**（15% 不足）。

∴ **「`calib_na` は転移している」という一般化は撤回し、「**通常攻撃枠は burst 枠ほど壊れていない**」に弱める。**
⚠ CLAUDE.md 開発ルール §5 の「肯定側の実例」の記述を更新する必要がある（本書 §7）。
