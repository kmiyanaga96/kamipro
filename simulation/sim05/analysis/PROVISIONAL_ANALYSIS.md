## 1. 結論（3行）

1. **T1 の乖離 ×2.47 は「手数 ×1.39」×「ダメージモデル ×1.77」の積**だった。実機の押し順を強制し
   `abilCapPerTurn` を外すと、シムは実機 42手中 **39手**を再生でき、残る差は純粋にモデルの過小になる。
2. **モデル側の乖離 ×1.77 の 77.5% は2グループだけ**＝ **betaia（40.1%・cap 過小）** と
   **バースト「追加ダメージ」4種（37.4%・cap 非拘束＝式が違う）**。**バースト本体は ×1.04 で一致**。
3. **T2/T3 は較正に使えない**。実機は T1 でアビ上限を超えて**バフを消去**されており、シムはそれを持たない。
   ∴ **clean anchor は T1 のみ**（要件4ターンに対し**1**）。

## 5. 較正方針の変更（★重要）

README §4.3 は「**非会心・非急所の非飽和アンカー**で fit する」と規定しているが、
**実機の装備（スティンガー武器＝急所確率UP）では全ヒットが会心・急所になり、この原則は成立しない**。

代替案（本trial設計時にユーザーと確定する）:

- **(a) 常時会心・常時急所を前提に突き合わせる**: シム側も `crit_rate` は既に 1.0 クランプ。
  **急所だけが「発動率×倍率」の期待値のまま**なので、`acute_*` を**確定発動の倍率**として評価する
  条件を較正専用に作る。→ シムが系統的に低く出るバイアスを除ける。
- **(b) 急所の実効倍率を実機から逆算する**: 同一条件の複数ヒットの**分散**から会心/急所の乗り方を推定。
  ⚠ pre-trial では betaia が合算表示・追加ダメが1発ずつなので、**サンプルが足りない**。
- ⚠ いずれにせよ **C40/C41 の乖離（×2.9〜7.1）は急所倍率（1.05〜1.30 級）では説明できない大きさ**なので、
  この方針変更は**残差を詰める段階の話**であって、C40/C41 の起票を揺るがさない。

## 7. この分析の限界（誠実な留保）
