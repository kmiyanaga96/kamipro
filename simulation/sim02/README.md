# sim02 — T2 漸進較正（turn-by-turn ホライズン = T2）

- **方針**: **B案＝厳密 turn-by-turn**（ユーザー決定）。sim 毎に「検証済みホライズン」を1ターン伸ばす。
  sim01 で T1(+α) を検証（C5 確定）済み → **sim02 はホライズンを T2 へ拡張**する。
- **主題**: シムが **T2 の挙動を実機と系統誤差なく・序数一致で再現するか**を検証し、ズレがあれば系統誤差
  （cap/frame/倍率・トリガー）として特定・較正する。T2 を序数フィクスチャとして固定する。
- **非対象**:
  - **T2 絶対総ダメージの一致は追わない**（PHASE4_PLAN §2＝蓄積誤差C2には頑健・系統誤差だけ狙う）。
  - **C1（テトラHELIX後追撃cap）は sim02 の対象外**。HELIX は T6〜T7 到達が前提のため、ホライズンが
    そのターンに達する **≈sim06〜07 で自然確定**する。C1 確定用の逆算メソッド（会心相殺の証明つき）は
    `CALIBRATION_ANALYSIS.md` の C1 バックログへ退避済み（その時に使う）。
- **状態**: **データ待ち**（T2較正フォーム用意済み）。

## なぜ B（turn-by-turn）か（決定経緯）
会心の分離測定が実機で不可能なため、単一成分の抜き取り較正は単一サンプル・会心RNGに脆い。
ターンを1つずつ前進し、各ターンで**系統誤差／序数**を潰してホライズンを固定していく方が堅牢で、
序数フィクスチャ（PHASE4_PLAN §4）の素材もターン単位で貯まる。C1 は先送りになるが、ホライズンが
HELIX ターンに到達した時点で「前段が全て固定済み＝残差が HELIX追撃に局在」する形で確実に確定できる。
（Antigravity は会心相殺式での C1 即確定を承認していたが、ユーザー判断で堅牢性を優先し B を採用。）

## T2 較正のやり方（系統誤差・序数の診断）
1. 実機の T1→T2 走を `raw_data.txt` に記入（T1は state を作るための押し順、T2が検証本体）。
2. その押し順をシムのリプレイモードで再生し、`replay_screenshots.md` へ実機/シム双方を転記。
3. **系統誤差の診断**: T2 の各成分（バースト本体/ストリーク/ジャッジ/追撃/英霊武器/通常）について、
   実機とシムで**構造的な比率ズレ**が無いか確認（絶対値一致ではなく「ある成分だけ系統的にズレる」を探す）。
4. **序数判定**: T2 に対抗手順 A/B があれば、`sign(simA−simB)` が実機の `A>B` と一致するか確認（PHASE4 §2-4）。
5. ズレが系統誤差なら原因（cap/frame/倍率・トリガー）を特定し `CALIBRATION_ANALYSIS.md` に Cx 起票 → 較正。
6. T2 を序数フィクスチャ化し、**ホライズン=T2 を固定**。次は sim03 で T3 へ。

## 残存バフの扱い（転記時の注意・2系統で正反対）
ターン総和ではなく成分構造を見るため、バフの効き方の区別は引き続き重要（コード `_na()`/`_decay` 準拠）:
- **① 倍率系**（攻撃力/アサルト/属性/旺盛/会心/急所/特殊攻撃）… `_na()` に内包＝測定ターンの値に自動で入る。
- **② アビ上限UP系** … `_decay` の `(1+GEAR.abi_cap)` に効くが naB に入らない。残存していれば**較正ギャップ候補**として記録。
- **会心**: シムは期待会心、実機は実現会心。**T2絶対総和を会心RNGで突き合わせない**（序数・系統で見る）。

## 較正ボス
**ヴァルプルギス・ロキ**（幻属性／`ENEMY_REGISTRY.walpurgis_loki`・詳細 `enemies/walpurgis_loki.md`）を採用。
ムーンコードで被弾無効化しソロ生存＝B のホライズン全域を1体でカバー。`applyEnemy('walpurgis_loki')` で
**affinity=1.5（光→幻=有利・幻は相互有利・[実機]）**・def=10(暫定)・HP=9.8億(実機) を適用。均一×1.5は序数/成分比で相殺。

### ★較正の必須注意：HP依存の2フェーズ被ダメ倍率（[web]確認・現行シム未モデル化）
- **HP>50%（フェーズ1）= 常時30%カット → 我々の与ダメ ×0.7**。
- **HP50%「ファントムリリース」後 = カット解除＋被ダメ+20% → ×1.2**（同時に敵が火力UP）。
- 含意: 序数A/B・成分比は**同一フェーズなら相殺**。だが**フェーズを跨ぐ比較・絶対逆算（C1）はこの倍率を必ず除算**。
  → 各測定ターンで**ボスHP%（50%超/未満）を必ず記録**（HELIXターンT6-7は境界を跨ぎうる）。
- HP=9.8億は実機確定。**def=10は暫定**（実機データ複数回で確定予定）。絶対値較正の前に def を再確認。
