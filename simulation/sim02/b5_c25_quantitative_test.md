# sim02 — C25定量テスト: 「cap外し（会心・急所を減衰後乗算）」試作モデルの照合結果（B5）

> 2026-07-12 Claude Code。C25 の検証計画 (b) を既存データのみで実行。**試作変換**＝`_na()` の会心・急所期待値係数を
> raw から除去（cap連鎖含め正確に再構成）→同一 `_decay` を通す→実機の会心/急所マークどおり ×1.5^crit ×θ^acute を後乗算し、
> 実機サンプル24点で **θ（急所実効倍率）の一貫性**を検定した。ハーネス: scratchpad `replay5.mjs`（B3/B4と同一re-play基盤・新実機ATK・def=10）。

## 1. 結果: 単純な「cap外し」モデルは**棄却**

| サンプル群 | 必要θ | 矛盾点 |
|---|---|---|
| バースト本体（T1 会心急所） | 1.09〜1.19 | — |
| バースト本体（T4 会心急所） | 1.57〜1.67 | T1と不整合（θがターンで成長） |
| バースト追撃（T1/T2 会心急所） | 2.90〜4.30 | coreと桁違い |
| バースト追撃（T4/T6） | 2.44〜2.54 | 〃 |
| **ヤマトT1 core（会心のみ・θ不要）** | — | **予測639万 vs 実機485万＝32%過剰予測**（現行モデルの98%の方が合う） |
| **streak統制** | — | strip後 782/849万 vs 実機 1033/1223万＝**stripで統制が崩れる** |

- **単一の (crit=1.5, θ) では全成分を同時整合できない**（θ≈1.2 と ≈3 と ≈1.6 が併存）。
- ヤマトT1（会心のみ＝θの自由度なし）で cap外しは**過剰**予測・現行モデルは98%一致＝**深飽和成分では「cap内側」の現行構造が実測に合う**。

## 2. 自己訂正: B4 の streak 論拠は「順序」ではなく「飽和」の証拠だった

- streak・ヤマトT1 core は**減衰カーブの深飽和域**にあり、raw の大小に鈍感＝**現行モデルと一致するのは cap値・slope が正しいから**であり、会心の順序とは無関係だった（B4 §4 の①を訂正）。
- 逆に**非飽和〜浅飽和の成分だけが系統的に不足**する。∴ 乖離の正体は cap の位置ではなく **pre-cap の raw が過小**。

## 3. 再定式化: 乖離は raw レベルに局在し、成分・キャラで不均質

減衰カーブ（検証済み）を逆関数として実機 raw を逆算すると:
1. **バースト本体**: 実機/シムの出力比 64〜74%（T1）→ 49〜51%（T4）。slope 0.10 を通した raw 比では T4 で×3級の差。
   ただし**ヤマトだけ T1 98%/T4 74% と大幅に良い**＝ヤマト selfBonus（現神/奮起）の過大 or 他キャラの raw 過小、のキャラ不均質が併存。
2. **バースト追撃**: シムは T4 で cap 飽和（≈195〜205万）だが実機は 737〜770万＝**crit順序をどう置いても現行 cap値（C5較正値）では到達不能**。
   ∴ **追撃は式/capレベルの独立乖離**（C5 の再較正が必要・C3 のエジソン追撃cap実測と同じ問題系＝合流）。
   ※C5 は試行1系データ＋「cap内側」前提で較正した値＝前提ごと見直し対象。
3. **通常（na）**: 実機 106万 は na cap 域を大きく超え、slope 0.5 逆算で raw ≈2.4×シム＝coreと同方向の raw 不足。
- **C7除去後も B1 の F1（ターン跨ぎの成長不足）は正味で実在**（T1→T4 で不足が拡大）。B3 の「フラットスカラ」は集計の偶然（B4）、B4 の「cap順序」は飽和の錯覚（本書）＝**残るのは「raw の baseline 不足＋成長不足＋追撃の式レベル乖離」**。

## 4. 帰結と必要データ（→ sim03 測定プロトコルへ）

- 現行データでは「raw 不足」を **naB の中のどの枠**（GEAR_K/assault/旺盛/属性/特殊…）に帰属させる自由度が残らない
  （全サンプルに会心/急所が乗り、非会心アンカーが streak（飽和・鈍感）しかない）。
- **決定打＝非会心・非急所の非飽和サンプル**: 各成分（通常/バースト本体/追撃/ロボ追撃）で non-crit non-acute の単発実測が1点ずつあれば、
  raw を直接読める（会心の交絡なし）＝ baseline の枠帰属と成長差の枠局在（B1 next-action 3）が一挙に進む。
- 追撃は **LB II 充足後のエジソン英霊武器**（C26ユーザー回答: 実機装備済み・最終限界突破II未達＝シム満凸スペックと不整合）を含め、
  **非会心追撃の飽和値**から cap を直接再較正する（C3 の第2回実測と統合）。
- → 以上を **sim03 の測定プロトコル**として設計（`simulation/sim03/README.md`）。
