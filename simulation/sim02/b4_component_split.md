## 3. ★確定バグ: 試行2の探索は「エジソン英霊武器追撃 OFF」で走っていた

- `DMG.edison_burst_extra_mult` は既定0（OFF）で、UI `applyGear()` の英霊武器スロット（ランチャータンク）でのみ有効化される。
- **B3 の fidelity 完全一致（10T総ダメがキャッシュ値と1円単位で一致）が、mult=0 での一致**＝**探索キャッシュ自体が追撃OFFの世界で生成された**ことの証明。
- 一方実機は T1 445万→T4 1001万→T5 901万 と**攻撃フェイズ最大級の成分**として毎ターン出ている。
  ∴ 推奨順は「エジソンのバースト価値を一貫して過小評価した探索」の産物（序数への影響は要評価だが、エジソン系押下の優先度が系統的に歪む）。
- **併発の機構問題**: 結果キャッシュのキー（`_configSig`＝hero/kamihime/GEAR/SUBS/def/hp/n）は `edison_burst_extra_mult` を**含まない**
  ＝英霊武器の有無だけが違う2設定が同一キーに衝突（stale cache ハザード）。→ **C26 起票**。
- 原因切り分け（ユーザー確認要）: UIの武器スロット0にランチャータンクが未設定だったか、設定済みでもGEAR適用経路に漏れがあるか。

## 4. 構造仮説（C25 起票）: 減衰capの適用位置が会心・急所の「内側」なのが誤り

観測パターンが一貫して指すもの:
1. **streak（実機ログで唯一会心マークが付かない成分）だけが 100%/102% と完全一致** — streak の減衰cap・式は正しい。
2. **会心マーク付き成分はすべて sim を大きく超過**し、超過率はおおむね×1.5〜×2級（会心1.5×急所1.3≈1.95 のレンジ）〜追撃では×2.5-3.7。
3. 実機の capped 級成分（追撃・通常）が**ターン経過（バフ蓄積）でなお成長**する＝実機では cap 後に乗算される可変係数（会心/急所倍率）が存在する挙動。
4. B1 が「naB の baseline 2×過小」とした観測も、**sim が会心/急所を期待値として cap の内側（`_na()`）に畳んでいる**ことで説明可能
   （実機: cap(素ダメ)×会心×急所 ／ sim: cap(素ダメ×E[会心]×E[急所])＝**capが実質的に低すぎる**）。
- **検証方法（決定的・実機追加取得なしで可能な範囲）**: 実機ログの**非会心・非急所サンプル**（例: 試行1 T1 テトラ通常54万）と
  sim の cap 済み素ダメを直接照合（一致すれば仮説確定・会心分は既存サンプルの ×1.5/×急所 で逆算検証）。
  会心/急所を `_na()` から外し `_decay` 後の乗算へ移す試作モデルで T1〜T5 全成分の同時整合を確認→golden 再fit。
- 残差候補: 追撃の 27〜41% は会心急所（×1.95）だけでは埋まらない（×2.5〜3.7）＝**追撃はcap値そのもの（C5較正値）or cap上昇レバーの併存疑い**。C3（エジソン追撃cap実測）と合流させて確定する。

## 5. B3 の読み替え（自己訂正）

- B3 の「フラットスカラ≈0.65」は**集計レベルの偶然の均し**だった（会心付き成分の不足と streak/飽和成分の一致が混ざった平均）。
  スカラ1本較正の見通し（B3 §4-2）は**撤回**し、C25 の構造修正を絶対値較正の前提とする。
- B3 の C7 逆証拠（境界不連続・リリース跨ぎ連続）は成分分解でも不変＝**C7 改訂の結論は維持**。
- B2 の def 単独仮説は棄却（§1）。ただし「共有スカラの署名」という観察自体は、会心期待値の一律畳み込み（全キャラ共通の E[会心]×E[急所] 係数）で説明でき、C25 と整合。
