## 試行1: 実機勘（Manual）押し順についての所感
> 2026-06-27 ユーザー記入。実機勘ルートには複数の手動ロスがあり、シム推奨の方針が火力的に正しそう、という総括。

### 全体所感
- **シム推奨の方針が妥当**: ヤマト1アビは火力UPに大いに貢献するため、シムの言うとおり**早期発動・リキャスト重視で
  ヤマト3アビを効率よく回す**のが、最も火力貢献度が高くなりそう。
- 実機勘ルートには下記のとおり手動ロス（JD空転・不要な再発動・HELIX撃ち忘れ）が複数あり、実機勘 < シム推奨 の一因。

### ターン別所感
- T1: —
- T2: エレイン3アビを再発動（**不要**。効果2T継続のため）。
- T3: —
- T4: エレイン3アビを再発動（**不要**）。
- T5: JDのリキャストを1回無駄にしている可能性（T5かT6のどちらか）。
- T6: エレイン3アビを再発動（**不要**）。JD空転がこちらの可能性も。
- T7: **連理魔力30到達時に[HELIX]テトラ（4アビ）を発動し忘れ**ている（手動ミス）。

### シムと乖離していそうな点（系統誤差の候補・要検証フラグ）
- **エレイン3アビ＝効果2ターン継続**。再発動不要タイミング（T2/T4/T6）での再発動が**エレイン4アビの発動を遅らせ**、
  結果として**エジソンのアビ効率が微かにDOWN**。→ シムが「エレイン3の2T継続」と「エレイン4/エジソン効率の連動」を
  正しく扱えているか要検証。
- **JDリキャストを1回空転**（T5/T6のどちらか）。→ ジャッジCD/リキャスト処理の確認材料。
- **HELIX撃ち忘れ（連理魔力30時）**。テトラ3アシの効果は数値に如実に表れている。
  → HELIX後テトラ追撃（C1較正）にも関わるため、シム推奨順データ（試行2）でHELIX発動時の挙動を要確認。

## 試行2: シム推奨順（Sim Opt）についての所感
> 2026-07-05 ユーザー記入（実機でシム推奨順を再現しようとして発生したトラブル報告）。総合分析未着手・仮説の種。

### 実機トラブル報告（→ C18 として起票・確認済）
- **T4の12アビ目のテトラ1（judg）が発動できない。** 推定原因＝T3で5回JDを発動しておりメインフェイズでリキャスト上限に達し、攻撃フェイズのバースト回数によるリキャストが行われず、T4は12回アビを発動する（＝13アビ目をテトラ1）にせざるを得ず、その先のアビがすべて使えなかった。
- **JD／コヴァレント・アルカナ仕様の再確認（ユーザー→Claude Code）**:
  - 「バースト2回」のリキャスト条件は**メインフェイズだけでなく攻撃フェイズも対象**。
  - よってメインでリキャスト上限5に達しないターンでも、**攻撃フェイズに5人がバーストするため2〜3の連理魔力が付与され、コヴァレント・アルカナで次ターン頭にJDが使用可能な状態**になっている。
  - **「火力が楽観的」という見立ては誤り**: 実機でもバフをある程度乗せてJDを撃つのは当然（高火力）。実機はJDリキャスト寸前までバフ・デバフを詰め込み、かつJDリキャストが重複（機会損失）しないよう非JDアビ順を慎重に管理している。

### 追加のユーザー仕様指摘（2026-07-07・診断の転回点）
- **「JD即発動（強制発火）」モデルは実機と違う**: JDはarmされたら**押下可能**になるだけで、押す位置はプレイヤー裁量（セオリー上、必要なら effond のデバフ等を先行させる）。#1強制はロボ・バフ前のJD発動を強いて火力ロス。→ 当初のC18診断（即発動未強制）は撤回。
- **ムーンコードの正確な仕様**（ヘカテー2アシのメイン効果）: 「**戦闘開始時または自分がアビリティ12回使用する毎に**ムーンコードが発動（回避UP・会心・旺盛・注目・回避時反撃10倍/最大3回/T）。**持続2ターン**（開始時発動も同じ）。12回目の押下で**即時**発動＝同一ターン後方のヘカテーアビは全てムーンコード状態」。ヘカテー2は「ムーンコード発動時、即座にゲージ消費なしでバースト」。累積カウントのゲーム内表示は無し。

### Claude Code 検証結果（最終・C18確定）
- **判帳簿は実機一致で正しい**（judg発火回数・renri蓄積・proc上限5・攻撃フェイズproc→次ターン cd.judg=0 キャリーオーバー）。
- **真因＝ムーンコードのモデル乖離**。決定的証拠は本試行1 raw_data 自身: ヘカテー2のバースト付与が **T1/T2/T3/T5/T7=有・T4/T6=無**（旧モデル=実質常時ONでは再現不能の交互パターン）。試行2 T4 では #5 effond がムーンコード切れでバーストせず→burst-2 proc不成立→judg未arm→**#12不可・12アビ目のprocでarm→13アビ目で可**＝実機報告と完全一致。
- **修正・検証完了**（CALIBRATION_ANALYSIS.md C18＝fixed）: `moon_acc`（自身アビ戦闘通算・12毎に発動）＋`onBattleStart`発動へ修正。旧推奨順replayで実機トラブルを完全再現（受入OK）。golden再fit: raw 173,574,719 / calibrated 202,230,823（override同値）。
