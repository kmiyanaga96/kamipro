## A. 準備査読（データ収集前・Antigravity 記入）
査読対象: `README.md`「準備ステップ記録」＋ `raw_data.txt`。観点は README の「Antigravity への査読観点」チェックリスト参照。
- **判定**: **承認（承認 / 測定時の推奨事項あり）**
- **指摘・推奨事項**:
  1. **会心（クリティカル）の減衰前乗算仕様と「会心なし」推奨の数学的背景**:
     - 神姫PROJECTのダメージ計算仕様において、会心は減衰前ダメージに乗算されます。これは `sim01` の実機データ（ヤマト追撃：通常262万 vs ヘカテー会心追撃：279万のように、会心が発生しても実ダメージが1.5倍にならず数％の微増に留まる挙動）から数学的に裏付けられています。
     - 会心データから逆算する場合、会心倍率（基礎1.5倍＋急所バフ等による補正）の正確な特定が必要となり、逆算式に不確定要素が混入します。そのため、READMEに記載されている通り**「通常（会心なし）の通常攻撃ダメージ naB および HELIX追撃ダメージ」を測定することを強く推奨**します。
  2. **アビ上限UP系バフの検証安全性**:
     - 現行のシミュレータエンジンは `_decay('abi', ...)` において装備アビ上限UP（`GEAR.abi_cap`）のみを参照しており、戦闘中の動的アビ上限UPバフを自動的に追撃に合算するロジックを持っていません。
     - 実機測定時にバフ由来のアビ上限UPが残存している場合、逆算式にその値を手動で加算する必要があるため、`raw_data.txt` の #1 に「残存バフ（アビ上限UP系）」の記入欄を設けている設計は極めて正確で安全です。
- **追加で必要な測定項目**: なし。1ターン圧縮で十分にベース減衰上限 $Cap_{\text{base}}$ の逆算が可能です。
