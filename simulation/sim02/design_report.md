## A. 準備査読（データ収集前）
### A-0. 方針決定の記録（ユーザー）
当初 sim02 は C1（テトラHELIX後cap）単発確定として設計し、Antigravity が会心相殺式で承認した（A-1 に保存）。
しかし**ユーザー判断により B案（厳密 turn-by-turn）を採用**し、sim02 を **T2 漸進較正**へ再定義した。
- 理由: 会心の分離測定が実機で不可能で、単一成分抜き取りは単一サンプル・会心RNGに脆い。ターンを1つずつ
  前進して系統誤差／序数を潰す方が堅牢で、序数フィクスチャ素材も貯まる。C1 はホライズンが HELIX ターンに
  到達する ≈sim06-07 で「前段固定済み＝残差が HELIX追撃に局在」する形で確定する。
- C1 の会心相殺逆算メソッド（A-1 の証明）は失わないよう `CALIBRATION_ANALYSIS.md` C1 バックログへ退避済み。

### A-1. （保存）Antigravity の C1 会心相殺証明 ※将来 C1 確定時に使用
両方会心（または両方通常）で naB と追撃を採れば会心倍率が相殺され、通常時と同一式でベース上限を求められる:
- 実ダメ = Cap_real + (raw − Cap_real)×0.04 = Cap_real×0.96 + naB×0.24　（raw = naB×6.0）
- **ベース上限 = (実ダメ − naB×0.24) / (0.96 × (1 + 総アビ上限UP))**
- Claude Code 補足: シムは crit-before-cap モデル（`_na()`内に期待会心→×6→`_decay`）。上式はその逆関数で
  自己整合。かつ raw≫cap のため結果は約9割が cap 項＝1回測定でも頑健。→ ホライズン到達時にこの式で確定する。
