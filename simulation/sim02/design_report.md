## A. 準備査読（データ収集前・Antigravity 記入）
査読対象: `README.md`「準備ステップ記録」＋ `raw_data.txt`。観点は README の「Antigravity への査読観点」チェックリスト参照。
- **判定**: **承認（会心データでの測定を正式採用し、条件を大幅に緩和）**
- **指摘・推奨事項**:
  1. **「会心前提の逆算モデル」へのアップデート（測定の技術的困難の克服）**:
     - 実機で「会心なし」を狙って測定することが極めて困難であるとのフィードバックを受け、数学的モデルを再検証しました。
     - **結論**: **「通常攻撃 naB」と「追撃ダメージ」の双方が会心（クリティカル）であれば、クリティカル倍率の値を陽に考慮することなく、通常時と全く同じ逆算式でベース上限を決定可能**です。
     - **数学的証明**:
       - 通常攻撃の会心ダメージを $naB_{\text{crit}}$ とします。追撃の減衰前ダメージ $raw_{\text{crit}}$ は通常攻撃（会心）の6倍となるため、$raw_{\text{crit}} = naB_{\text{crit}} \times 6.0$ です。
       - 実質上限を $Cap_{\text{real}} = Cap_{\text{base}} \times (1 + U)$ としたとき、減衰後の追撃実ダメ（会心）は以下の式になります：
         $$実ダメ_{\text{crit}} = Cap_{\text{real}} + (raw_{\text{crit}} - Cap_{\text{real}}) \times 0.04$$
         $$= Cap_{\text{real}} \times 0.96 + raw_{\text{crit}} \times 0.04$$
         $$= Cap_{\text{real}} \times 0.96 + naB_{\text{crit}} \times 0.24$$
       - 通常時（会心なし）の計算式も、$naB_{\text{norm}}$ と $raw_{\text{norm}} = naB_{\text{norm}} \times 6.0$ を用いて全く同じ形になります。
       - したがって、**「両方会心」または「両方通常」のいずれか同一状態で測定値（naB と 追撃実ダメ）を採取すれば、以下の単一の逆算式でベース上限 $Cap_{\text{base}}$ を完全に決定できます**：
         $$Cap_{\text{base}} = \frac{実ダメ - naB \times 0.24}{0.96 \times (1 + U)}$$
     - これにより、「会心を分離する」という測定の制約は不要となり、**通常通りの実戦バースト（会心連発状態）でそのままデータを採取していただけます**。
  2. **T2較正への転換案について**:
     - sim番号＝較正ターン数とする「T2実機較正」への切り替え案も非常に合理的です。しかし、T2における総ダメージ乖離（C2）は、多数のバフ・アビリティダメージが複雑に絡み合うため、較正の難易度が極めて高くなります。
     - 今回の「会心前提の逆算式」によって C1（テトラHELIX後追撃上限）の測定ハードルがほぼゼロになったため、当初の計画通り **sim02 で C1 を確定させてから T2 以降の較正に進む方が、手戻りが少なく長期的な押し順精度も確実に向上する**と判断します。
- **追加で必要な測定項目**: なし。会心状態の通常攻撃1発分 $naB_{\text{crit}}$ と、HELIX追撃ダメージ $実ダメ_{\text{crit}}$ を同一ターン・同一バフ状態で採取してください。
