# quantitative_analysis — 定量まとめ（trial横断・数学的分析のみ）

> **責務（rollup 層）**: **`analysis/per_trial/trialNN_quant.md`（全trial）のみ**を入力に、**trial横断**の定量分析を行う。
> 生 `data/trialNN.md` は再オープンしない（スポット確認のみ例外）。所感・統合は書かない（→qualitative / integrated）。
> - **trial横断ならではの分析**: 決定性（同slot hit値の複数走突合・分散分解）・平均/分散・**max_hp収束**・追撃cap・raw枠帰属・会心急所率の集約・経済回帰の集約。
> - **P3（再現性）**: 各節に「手法・使用スクリプト（scratchpad名）・入力（=どの per_trial ファイル）」を明記。

## 2. 決定性・分散分解（同slot hit値の5走突合／帰無=差分0・非0なら記録済み状態で層別）

**手法**: `rollup_xtrial.mjs` §A/B。5走とも固定押し順（シム推奨順）＝slotは (ターン, 押下#, hit成分) で完全対応。v=0（オーバーキル切断）は除外。全数表は付録A。

**結論: 「同一押し順・同一マークなら hit値一致」の帰無仮説は棄却**。会心マークが全走一致（ほぼ全hit会心）かつ**急所マークも5走一致のhitに限っても**、値は一致しない:

- 急所マーク5走一致のhit: n=59 / median=3.53% / p90=12.44% / max=16.09%
- 急所マーク不一致(混在)のhit: n=30 / median=4.58% / p90=14.47% / max=17.74%
- 全hit: n=89 / median=3.67% / p90=12.97% / max=17.74%

- 急所マーク一致群でも median 3.5%・p90 12.4% のスプレッド＝**記録済み状態（会心/急所/連撃/HP%）では説明できない per-hit の乗算ダメージロール RNG が実機に存在**する（シムは決定的期待値モデル＝未モデル化）。
- **スプレッドは減衰飽和度と強く逆相関**（cap/slopeモデルの独立検証になっている）:
  - 深飽和成分＝バーストストリーク 0.64〜1.24%・ロボ追撃 0.6〜3.2%・judg ph0 アビ 0.91〜1.44%・反撃 1.3% → post-cap は slope 倍に圧縮されたロールだけが残る。
  - 非飽和成分＝攻撃フェイズ burst/extra 4〜17%・メイン中バースト本体 1.8〜14% → pre-cap ロール（片側±5〜8%級）がそのまま見える。
- **撃破押下の分布**: T3#16 judg ×3走（tr01/04/05）・T3#17 alone ×2走（tr02/03）＝累積ロールが撃破位置を±1押下動かす（ユーザー所感「誤差で撃破アビ前後」の定量確認）。
- **通常攻撃の連撃（hit数不一致）**: judg ph2 の通常攻撃が 1〜3hit と走・slotで変動（§E表）。シムは常に1hit＝**DA/TA（連続攻撃）が未モデル**。敵特性「連続攻撃確率UP」持ちでもあり、通常攻撃成分のターン合計が trial 間で最大2倍振れる主因。
