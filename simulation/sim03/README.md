> 2026-07-12 策定（Claude Code・sim02統合分析とB5の帰結を受けて）。**Antigravity はワークフロー除外**＝設計レポート/統合分析とも Claude Code 担当。
> 方針は引き続き **B案＝厳密 turn-by-turn**（sim02 で T2 を「押下可否・経済・序数骨格」の水準で固定済み → **sim03 はホライズンを T3 へ**）。
> ただし sim02 の最大の学び＝**絶対値乖離は pre-cap raw に局在し、非会心アンカーなしには枠帰属を確定できない**（C25・B5）ため、

## 前提条件（開始ゲート・すべて充足してから実測）

1. **ランチャータンク最終限界突破IIの充足**（ユーザー予定）— シムの満凸スペック（2.5倍/80万）と実機性能を一致させる（C26）。
2. **エジソン英霊武器追撃ONで再探索**し、その推奨順を試行対象とする（C26。`_configSig` は mult/cap 対応済み＝2026-07-12。
   UI武器スロット0の設定を確認のうえ探索を回し、**キャッシュJSONを本フォルダへ export**（sim02 と同形式・GEARスナップ同梱））。
3. 探索時の **UI装備パネルが実機現在値と一致**していること（表示ATK5値は `DISPLAY_ATK_OVERRIDE` 済み。装備スキル%・幻獣・サブアシも実機どおりに）。

## 測定プロトコル

### A. ★raw較正アンカー（C25の決定打・最優先）
現行データは全サンプルに会心/急所が乗り raw を直接読めない（streakは飽和で鈍感）。**非会心・非急所の単発実測**を以下の成分ごとに最低1点ずつ確保する:
- **通常攻撃**（テトラ三段の非会心hit等）
- **バースト本体**（どのキャラでも可・「会心」「急所」マークなしの本体値）
- **バースト追撃（追加ダメージ）** — C5再較正の直接証拠。**非会心追撃はcap飽和値の候補**＝同ターン複数サンプルで同値頭打ちなら cap 確定
- **ロボ追撃**
- **エジソン英霊武器追撃**（LB II 後スペック・C3第2回実測と統合）
記録様式: 「T・押下番号・キャラ/成分・値・会心/急所マークの有無」。低会心装備での短い別走（T1のみ）も選択肢（会心率が高く非会心が出ない場合）。

### B. バフ実stack数（成長不足の枠局在・B1 next-action 継承）
各ターン開始時（攻撃フェイズ後）に、画面で読めるバフの実スタック数/有効状態を記録:
アサルト系（バノーシク/アブソ/legend閾値）・旺盛・光属性UP（プヴワール/ヤマト）・特殊攻撃（omni/mobius）・防御DOWN。
→ シムreplayの同時点スタックと照合し、**raw成長不足がどの枠の蓄積差か**を特定する。

### C. 回帰アンカー（sim02で確立した完全一致の維持確認）
- 経済系: 各ターンのメインフェイズ開始/終了時の**契晶ストック/累計獲得/連理魔力**（sim02 は全10チェックポイント完全一致＝退行検知）。
- **バーストゲージ**: 各ターン開始時の5人分（C24 の ±5〜10 乖離の再測・エレイン1の対象条件観測: ゲージ付与アビの効果対象を可能な範囲でメモ）。
- **judg の re-arm 観測**（C23）: judg が押せる/押せない状態になった位置（特に12アビ目前後）をメモ。
- 各ターン末の**ボスHP%**（C7改訂の確定用: リリース跨ぎのダメージ連続性を再確認）。

### D. 通常記録（sim02と同じ）
押下毎のダメージ内訳（成分＋会心/急所マーク）・敵行動・反撃・DOT・撃破ターン。原本は `raw_data.txt`（加工せず）。

## 分析計画（データ受領後・Claude Code）

1. キャッシュ忠実度確認（B3方式: GEARスナップ＋サブアシで replay=キャッシュ総ダメ一致）。
2. **Aの非会心アンカーで raw を直接照合** → baseline 不足の枠帰属（GEAR_K/assault/旺盛/…）→ B と組み合わせ成長不足の枠局在 → モデル修正 → golden 再fit。
3. 追撃の非会心飽和値から **C5 cap 再較正**（C3統合）。
4. C23/C24 の特定・修正。T3 の序数フィクスチャ固定。
5. 設計レポート（5節構成）→ 統合分析 → **def 再fit → kill-turn ゲート再判定**（現状は延期中・ユーザー判断 2026-07-12）。
