## 1. 方針転換（2026-07-12 ユーザー合意・v1から不変）

**較正対象を「回数制限のない反復可能ボスバトル」へ転換し、統計的較正を導入する。**
- 背景: B案（turn-by-turn）は「会心の分離測定が実機で不可能＝単一サンプル・会心RNGに脆い」ことへの守りだった。
  反復可能ボスは this を覆す＝**N試行の集計で会心RNGを平均化・非会心アンカーを反復で捕捉・会心/急所率を頻度で実測**できる。
- 未定量の敵耐性は**最終ダメージに乗る単一の大域スカラ**（affinity/defと同種）＝
  **形状較正（会心率・baseline・成長・cap×会心順序・成分比）は比/形状ベースのため耐性に非依存**で成立する。
  ※モデルとボス耐性を**同時にfitしない**（識別不能）: 形状→有利ボスでレベル→残差で耐性、の順に解く。
- **キャスパリーグはこの転換ロジックの理想形**: 闇属性（光有利アンカー）＋「ライトレジスト＝光*以外*への耐性UP」が敵特性
  として明文化＝**我々（光編成）に隠れ耐性スカラが掛からないことがゲーム内記述で保証**＝絶対レベルアンカーとして最適。

## 3. 測定プロトコル v3（キャスパリーグ具体化）

### 3.0 ボス固有の設計制約（enemies/cath_palug.md からの帰結）

キャスパリーグはフィンブルヴェトルより**較正衛生が格段に良い**（交絡が構造的に少ない）。v2の系統交絡3種のうち2種が消える:

1. **full-crit ≈100% は「決定的」＝統計の主レバーは分散分解**（v2から不変）: 同一押し順・同一記録状態なら我々のフェイズの
   hit毎値は試行間で一致するはず。**不一致はすべて「未記録の状態差」か「モデル誤差」に局在**（会心RNGノイズと切り分け不要）。
   ∴ 少数試行で足りる。
2. **絶対レベルアンカーの本命（キャスパリーグ最大の価値）**: 闇属性＝光→闇 有利×1.5（既知）＋**ライトレジスト＝光以外への
   耐性UP＝光編成には非適用**（敵特性記述で保証）。∴ **隠れ耐性スカラ=1 と仮定できる根拠がボス側にある**（フィンブルの§3.0-7の
   「仮定」が、ここでは敵特性の明文記述に格上げ）。→ 交絡なしターンの hit値と affinity=1.5 既知で**レベルスカラを直接推定**。
3. **ディスペルの自然実験（stack=0 baseline）**: 「チョットホンキニャン」（HP50%以下・1回）が味方バフ全消去。T1でHP50%を跨ぐと
   敵フェイズでディスペル→**T2開始が stack=0 の既知クリーン状態**＝C25 baseline/成長分解のアンカーが1戦で取れる。発動有無・タイミング必記。
4. **消える交絡（フィンブル比の改善）**:
   - **敵防御UPドリフト → 無し**（行動リストに防御UPなし＝攻撃UP/回避UP/連続攻撃確率UPのみ）。毎ターンFB維持の較正衛生も不要。
   - **味方ゲージDOWN → 無し**（リストになし）＝ゲージ経済がクリーン＝**シム推奨順が実機で実行不能になるリスクが激減**（§3.1の押し順選択に直結）＋C24のゲージ2点測定に好適。
5. **残る注意点**:
   - **回避率UP（ハシルニャン・4の倍数ターン）**: 我々の攻撃がMISSしうる＝ダメージ欠測。**ただし2T討伐なら発動前に決着**＝第1バッチでは非交絡。長引いた走のみMISS記録。
   - **味方HP減（ハジマルニャン等の全体攻撃）**: 旺盛×HP結合（H2）の検証は継続＝味方HP%を記録。
   - **「猫鈴の音」→ネコリングパワー（敵の闇攻撃UP）**: 敵の与ダメ側＝生存の話。我々の与ダメには無関係。
6. **ホライズン制約（2T）**: HELIXターン（C1）・後半ターンの経済/judg通算・成長カーブの長区間は**観測不能**＝後続の長寿命ボスへ委譲。
   sim03 は「**絶対レベル＋raw枠帰属＋会心/急所率＋C24ゲージ2点**」に焦点を絞る（元々sim03の中核目的＝達成可能）。
7. **max_hp 推定の注意（2T討伐＝オーバーキル切断）**: 撃破時累計表示ダメは**上界**になりうる（最後の一撃が過剰）。
   **T1終了時ボスHP%の記録が推定精度の鍵**（`max_hp ≈ ΣT1ダメ / (1 − T1終了HP%)`）。HP%は必記。

### 3.1 測定モードと固定押し順

**測定モード＝D（全深測定撃破）に統合**: 2T討伐かつ交絡が少ないため、v2のK（撃破反復・粗ログ）とP（部分深測定）を分ける必要がない。
**1走まるごと（T1〜T2）を hit毎精密記録**（§3.2）＝撃破反復と深測定を1モードで両立。

**固定押し順（第1バッチ）＝シム推奨順に確定（2026-07-14 ユーザー決定）**:
- キャスパリーグはゲージDOWNなし＝シム推奨順の実行不能リスクが消失したため採用。configA（`data/configA.json`）の**T1（19手）/T2（24手）/T3（25手・撃破まで）**を固定順とする（`data/record_skeleton.md` に採録＝これを複製して trial01〜05 を作る）。**⚠実測は3T討伐**（trial01=T3#16撃破。当初「2T討伐確実」想定は誤り）＝**T3も固定順で実行し撃破まで記録**。**押し順はLv95 dispAtk更新後の再export順（2026-07-15・総ダメ1,644,858,119）に更新済み**。
- 効果: (a) replay照合が slot単位で完全対応＝精度最大 (b) **オプティマイザ自体の序数検証**（シムが並べた順が実機で本当に強いか）が第1バッチで同時に取れる。
- **統計要件（不変）**: 全trial（trial01〜05）を**同一のこのシム順**で回すこと（試行間のブレを会心/急所RNG＋敵行動のみに限定＝分散分解の前提）。逸脱時はメタヘッダに記録。

**第1バッチ配分＝D×5に確定（2026-07-14 ユーザー決定）**:
- D×5走（全hit毎記録）→中間分析ゲート（下記）→第2バッチ（序数A/B・追加走など）。
- full-crit決定的＝分散分解が主レバー＝少数（5走）で決定性が確認できれば十分。2T討伐＝1走が安いため増分も容易。
- **中間分析ゲート**: ① D走間で hit毎値の決定性が成立したか（不成立→未記録状態の特定） ② 敵行動スケジュールの試行間安定性
  ③ max_hp 推定の収束幅（T1終了HP%の分散） ④ ディスペル（チョットホンキニャン）発動の一貫性＝stack=0アンカーの取得可否。

### 3.2 記録項目（trialXX.md・1試行1ファイル・メタヘッダ必須）

**メタヘッダ（全走共通）**: 試行番号／日付／モード=D／装備config名=configA／ENGINE_VERSION=C27-red-after-setup-refine／
使用キャッシュ（configA.json・キャスパリーグ版）／UI装備一致確認（表示ATK5人分）／固定押し順（シム推奨順 or 実績ライン・逸脱の有無）。

**hit毎・全ターン（T1〜T3＝実測3T討伐。trial01=T3#16撃破）**:
- 押下毎・hit毎: キャラ／成分（通常/アビリティ/バースト本体/追加ダメージ/追撃/ロボ追撃/エジソン英霊武器追撃/judg/streak）／**値**／**会心・急所マークの有無**
  （full-crit実測確認＝非100%ならそれ自体が発見）。
- **敵フェイズ／ターン終了時ダメージ（★max_hp導出に必須・シム非モデルの実ダメージ）**: DOTダメージ（発数×値）・反撃ダメージ（キャラ/値/会心急所）・その他。**全hit値とは別枠**で記録（実機例: T1終了時DOT10万×4／T2終了時ヘカテー反撃 会心急所＋DOT10万×4）。
- 各ターンのメインフェイズ開始/終了時: **契晶ストック/累計/連理魔力**（経済回帰・sim02全10点一致の維持確認）・**バーストゲージ5人分**（敵フェイズ前後差分）・**味方HP%5人分**（H2旺盛結合）。
- **C24（任意・低優先）**: ロボ反応のゲージ増分（補助+攻撃**合計でよい**＝実機は分離不可）。※旧「エレイン1ゲージ仕様」は**撤回**＝エレイン1は即バースト赤アビでゲージ効果なし（sim一致）。
- **英霊BG依存メモ（任意）**: エレイン2=全体化の有無／エレイン3=与ダメDOWN付与の有無（英霊BG依存・観測できれば）。
- **C23追検証**: 各ターン最初のjudgのフェーズ（アビ=ph0/バースト=ph1/通常=ph2）。
- バフ実stack（**任意・見える範囲でよい**）: アサルト系/旺盛/光属性UP/legend閾値/特殊/敵防御DOWN。ターン開始時＋**ディスペル直後（=0確認）**。見えない枠は空欄・不明は「?」。
- 各ターン: **開始時ボスHP%**（特に**各ターン終了時HP%＝max_hp推定の鍵**）・敵行動名（ハジマルニャン/ドウシタラニャン/チョットホンキニャン等）・
  ディスペル有無とタイミング・回避率UP発動の有無（MISS要因）・（視認できれば）「猫鈴の音」の個数。
- 撃破: 撃破ターン・撃破押下#。**表示累計ダメは実機に出ない**ため、max_hpは各ターンHP%差÷実ダメ合計（全hit＋DOT＋反撃）で推定（§3.3）。

### 3.4 分析フロー（新構造・責務厳守＝**情報の多さと正確さを最優先**・v2から不変）

> **フロー厳守**: 定量↔定性の相互混入禁止。統合は両rollupのみを入力とし、新規集計・新規所感は各analysisへ差し戻す。
> **情報量の原則**: 要約より網羅。集計表は全数掲載（曖昧な値も確度タグ付きで残す）。乖離は選別せず全件列挙。すべての数値に出典（trialNN・slot）を付す。
> **2層構造（コンテキスト有界化・2026-07-15 ユーザー決定）**: `trial → per_trial/(trialNN_quant, trialNN_quali) → (quantitative, qualitative) rollup → integrated`。
> 生trial（大）を読むのは per_trial 層だけ・rollup 以降は小さい per_trial ファイルのみ。**trial横断分析（決定性/分散/max_hp収束）は rollup 専用**。

1. **per_trial（trial毎・中間集計）**: 各 `data/trialNN.md` を入力に
   - `analysis/per_trial/trialNN_quant.md`（数値のみ）: そのtrialの成分別集計／ターン別実ダメ合計（全hit＋DOT＋反撃）／HP%↔ダメ整合（単trial max_hp点推定）／会心急所率／judgフェーズ予実／経済チェックポイント／ゲージ。
   - `analysis/per_trial/trialNN_quali.md`（言語のみ）: そのtrialの所感・観測メモ・仮説の種。
2. **`analysis/quantitative_analysis.md`（rollup・定量まとめ・P3厳守）**: **per_trial/*_quant 全trial**を入力に**trial横断**。予定テーブル:
   決定性突合（D走間slot対slot全数）／絶対レベル推定／成分別rawアンカー表（vs シム同slot・C25）／追撃hit値表（vs cap・C5/C3）／max_hp収束／経済チェックポイント集約／judgフェーズ予実／C24ゲージ。各節に**手法・スクリプト参照・入力（=どのper_trial）**を明記。
3. **`analysis/qualitative_analysis.md`（rollup・定性まとめ）**: per_trial/*_quali 全trialを入力に横断テーマ（H2旺盛×HP結合／回避UP発動時のMISS挙動／ディスペル観測）。演算を書かない。
4. **`analysis/integrated_analysis.md`（統合のみ）**: 両rollupのみに基づく統合→較正案→**goldenへの影響を scratchpad で実測**→
   モデル修正（C25 raw帰属→C5/C3追撃→絶対レベル→def/耐性スカラ）→golden再fit→ kill-turnゲート再判定（延期中）。
5. 確定した較正は `DMG`/`CHAR_REGISTRY` へ宣言的に実装し、CALIBRATION_ANALYSIS.md の Cx を更新。sim03/README に1ページ要約。
