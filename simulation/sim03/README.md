## 1. 方針転換（2026-07-12 ユーザー合意・v1から不変）

**較正対象を「回数制限のない反復可能ボスバトル」へ転換し、統計的較正を導入する。**
- 背景: B案（turn-by-turn）は「会心の分離測定が実機で不可能＝単一サンプル・会心RNGに脆い」ことへの守りだった。
  反復可能ボスは this を覆す＝**N試行の集計で会心RNGを平均化・非会心アンカーを反復で捕捉・会心/急所率を頻度で実測**できる。
- 未定量の敵耐性は**最終ダメージに乗る単一の大域スカラ**（affinity/defと同種）＝
  **形状較正（会心率・baseline・成長・cap×会心順序・成分比）は比/形状ベースのため耐性に非依存**で成立する。
  ※モデルとボス耐性を**同時にfitしない**（識別不能）: 形状→有利ボスでレベル→残差で耐性、の順に解く。

## 3. 測定プロトコル v2（フィンブルヴェトル具体化）

### 3.0 ボス固有の設計制約（enemies/fimbulvetr.md からの帰結）

v1 の汎用プロトコル（装備2config×2×2分離）は、本ボスの実態に合わせて以下のとおり再配分する:

1. **config B（crit-off）は本ボスで実施しない（P4延期・ユーザー承認済み）**: 強敵ゆえウェポンダウングレードは非現実的。
   フィンブルヴェトルは **config A（full-crit・現行装備）専任**＝2×2表の「有利×会心あり」セルのみを担当。
   非会心・非急所セル（crit-off／中立ボス）は**第2走・より弱い反復ボス**へ委譲する。
2. **full-crit ≈100% は「決定的」＝統計の主レバーが変わる**: 本ボスでの反復の価値は「会心RNGの平均化」ではなく
   **分散分解**にある——同一押し順・同一記録状態なら我々のフェイズのhit毎値は試行間で一致するはずで、
   **不一致はすべて「未記録の状態差」か「モデル誤差」に局在**する（RNBノイズと切り分け不要）。少数試行で足りる根拠。
3. **ディスペルの自然実験（本ボス最大の贈り物）**: ファントムストーム（HP100%以下・1回＝実質序盤確定）・
   黄昏のヴァルプルギス（HP50%以下・1回）・ラグナロクディザスター（HP15%以下・1回）が**味方の強化効果を全消去**する。
   → 各ディスペル直後のターンは**バフstack=0 が既知のクリーン状態**＝C25 の baseline/成長分解に必要な
   「stack既知アンカー」が装備を触らずに手に入る。1回の撃破で成長カーブが**2〜3セグメント**取れる（各セグメントは0から再成長）。
4. **系統交絡が3種ある＝記録で中和する**（本ボスの絶対値アンカーはこの3つの記録が揃ったターンのみ有効）:
   - **敵防御UPドリフト**: エネミーバースト条件1（HP51%以上・永続累積）＋マジックブラスト条件1（毎ターン条件を満たさない場合）。
     → **毎ターン5回バースト（FB）維持が較正衛生**＝マジックブラスト系は抑止できる（ユーザーは達成済み）。
     エネミーバースト発動は不可避のため**発動ターンを台帳記録**し、以降のアンカーは「防御UP n個」を条件として層別する。
   - **味方への攻撃DOWN**: カオス・ストーム各段・エネミーバースト条件2が味方に攻撃DOWNを付与→我々のraw与ダメが系統的に低下。
     → 毎ターン**味方側デバフアイコンを記録**し、攻撃DOWN中のhit値はアンカーから除外（または層別）。
   - **味方HP減 × 旺盛結合（仮説）**: ユーザー所感「HPをわずかに削られた→HP未実装で若干の誤差」。編成バフに旺盛系
     （HP依存で効果量が変わる）があれば、被弾による味方HP%低下が与ダメの系統誤差になる。
     → 毎ターン**味方HP%を記録**し、hit値との相関を定量分析で検証（H2）。黄昏のヴァルプルギスの「HPを1%まで減らす」が
     味方対象なら強烈な自然実験になる（対象の実機確認＝定性項目）。
5. **バーストゲージDOWN ≈ −100（未モデル化）**: 原文ではカオス・ストーム（3の倍数T かつ HP50%以下）にのみ記載。
   シムはゲージDOWNを持たない→**HP50%以下の3の倍数T以降、シムのゲージ軌道は実機から系統的に乖離**する。
   → 敵フェイズ前後のゲージ差分でDOWN量を実測（H1: −100）。**シム推奨順が実機でゲージ的に実行可能か**は独立の検証項目
   （不可能ならモデル化要否の判断材料＝新Cx候補）。
6. **急所は常時ON**（幻＝相互有利で光→幻は有利属性）: 本ボスで急所の隔離はできない（中立ボスの第2走マター）。
7. **絶対レベルのアンカー適格性**: affinity=1.5 は既知（walpurgis実機確定の相互有利則）。エンドボスの「有利属性以外からの
   攻撃耐性」は**我々の攻撃が有利属性である以上、適用されない見込み**＝隠れスカラなしと仮定して絶対レベルアンカーに使える。
   ただし仮定であることを明記し、walpurgis 系アンカーとの残差整合で事後検証する。

### 3.1 測定モードと固定押し順

**固定押し順（第1バッチ）＝ユーザー実績ライン（毎ターンFB・HELIX・7T撃破の勝ち筋）を採用する。**
- 理由: 統計的較正の要件は「**固定・再現可能**な押し順」であり、シム最適である必要はない。シム推奨順はゲージDOWN未モデル化
  のため**実機でゲージ不足により実行不能のリスク**があり、実証済みラインの方が第1バッチとして安全。
- trial01 で実績ラインを**押下列として精密採録**し、以降の試行はそれを再現する（逸脱したら逸脱内容をメタヘッダに記録）。
- シム推奨順（ゲート2のキャッシュ受領後）は、まず**リプレイモードで机上のゲージ実行可能性を照合**してから、
  第2バッチ以降での採用可否を判断する。

| モード | 内容 | 第1バッチ | 主目的 |
|---|---|---|---|
| **K（撃破反復・粗ログ）** | T1→撃破まで完走。ターン粒度の記録（§3.2共通項目） | **3走** | ボス挙動マップ（行動×ターン×HP%）・max_hp推定・ゲージDOWN実測・FB達成の再現性・経済回帰・成長カーブのセグメント構造 |
| **P（部分深測定・hit毎精密）** | **T1〜T3のみ** hit毎の精密記録（§3.2深測定項目）。T4以降は記録せず自由に完走（撃破/撤退任意） | **3走** | C25 rawアンカー（決定性の直接検証）・C5/C3追撃hit値・ファントムストーム後のstack=0 baselineアンカー・成分比・C24ゲージ2点 |
| **B（境界深測定）** | 50%跨ぎ（黄昏前後）＋HP50%以下の3の倍数Tを深測定 | **第2バッチ候補**（中間分析後に配分決定） | H2旺盛×HP結合・ゲージDOWN正確値・黄昏後の再成長・カオス・ストーム段階挙動 |

- **P の窓を T1〜T3 とする理由**: (a) ファントムストーム（序盤確定）→直後ターンの stack=0 baseline を含む
  (b) 通常 HP>50% でゲージDOWN・カオス・ストームの交絡がない (c) T3=3の倍数のファントムスパークル（HP51%以上）は
  被弾のみで与ダメ側に無交絡 (d) 深測定の実機負荷を1戦あたり最小に保つ。
- **段階式の中間分析ゲート（K3+P3受領後・追加配分の判断基準）**:
  ① P試行間で hit毎値の決定性が成立したか（不成立→未記録状態の特定を優先）
  ② ボス行動スケジュールが試行間で安定か（行動選択にRNGがあるか）
  ③ max_hp 推定の収束幅
  ④ シム推奨順のゲージ実行可能性（replay机上照合）
  → これらの結果で第2バッチ（B投入・K/P増分・シム順採用）を決める。

### 3.2 記録項目（trialXX.md・P2形式=1試行1ファイル・冒頭メタヘッダ必須）

**メタヘッダ（全モード共通・毎試行）**: 試行番号／日付／モード（K/P/B）／装備config名（configA）／ENGINE_VERSION／
使用キャッシュファイル／UI装備パネル一致確認（ゲート3・表示ATK 5人分）／固定押し順からの逸脱の有無と内容。

**共通（全モード・ターン粒度）**:
- 各ターンのメインフェイズ開始/終了時: **契晶ストック/累計/連理魔力**（経済回帰・sim02全10点一致の維持確認）・
  **バーストゲージ5人分**（敵フェイズ前後差分→ゲージDOWN実測=H1）・**味方HP%（またはHPバー概況）**（H2旺盛結合）。
- 各ターン: バースト回数（FB有無＝マジックブラスト抑止確認）・**ターン開始時ボスHP%**・ターン中の与ダメ合計。
- 敵フェイズ: **発動した敵行動名**（ファントムストーム/スパークル/クラップ/カオス・ストーム/エネミーバースト/通常 等）・
  **ディスペル発生の有無とタイミング**・敵フェイズ後の**味方側デバフアイコン**（攻撃/防御DOWN等）・
  ボスのチャージ状況/バースト発動・（視認できれば）闇の魔力の個数・ボス防御UPアイコンの個数。
- **C23追検証**: 各ターン最初のjudgのフェーズ（アビ=ph0/バースト=ph1/通常=ph2）。
- 撃破時: 撃破ターン・最終累計与ダメ（→max_hp推定）。

**深測定（モードP・T1〜T3のみ追加）**:
- **押下毎・hit毎**: キャラ／成分（通常/バースト本体/追撃/ロボ追撃/エジソン英霊武器追撃/judg/streak）／**値**／
  **会心・急所マークの有無**（full-critの実測確認＝非100%ならそれ自体が発見）。
- **C24実機確認2点**: 補助ロボ（黄アビ反応）のゲージ増分実測／エレイン1のゲージ効果仕様（対象・英霊100条件）
  ——該当押下の直前直後でゲージ5人分を読む。
- バフ実stack数（アサルト系/旺盛/光属性UP/legend閾値/特殊/防御DOWN）: 各ターン開始時＋**ディスペル直後**（=0確認）。

### 3.4 分析フロー（新構造・責務厳守＝**情報の多さと正確さを最優先**）

> **フロー厳守**: 定量↔定性の相互混入禁止。統合は両analysisのみを入力とし、新規集計・新規所感は各analysisへ差し戻す。
> **情報量の原則**: 要約より網羅。集計表は全数掲載（曖昧な値も確度タグ付きで残す）。乖離は選別せず全件列挙。
> すべての数値に出典（trialXX・slot）を付す。

1. **`analysis/quantitative_analysis.md`（定量のみ・P3形式厳守）**: 各節に**手法・スクリプト参照（scratchpad/toolsパス）・
   入力データ（trialXX）を必ず明記**。最低限の予定テーブル:
   決定性突合（P試行間slot対slot全数）／replay照合（固定順のシム再生 vs 実機・全slot）／max_hp回帰／
   ボス行動頻度表／ゲージ差分表（行動別）／成分別rawアンカー表（vs シム同slot・C25）／追撃hit値表（vs cap・C5/C3）／
   経済チェックポイント全点／judgフェーズ予実／バフstack付き成長セグメント表。
2. **`analysis/qualitative_analysis.md`（定性のみ）**: ユーザー実機所感の verbatim 整理・Claude観測メモ・
   仮説台帳（H1: ゲージDOWN=−100はカオス・ストーム由来か／H2: 旺盛×HP結合／H3: 黄昏「HPを1%まで減らす」の対象は味方か／
   H4: エネミーバーストのHP50%以下時の挙動は原文未記載＝要観測）。演算を書かない。
3. **`analysis/integrated_analysis.md`（統合のみ）**: 両analysisのみに基づく統合→較正案→**goldenへの影響を scratchpad で実測**→
   モデル修正判断（C25 raw帰属→C5/C3追撃→絶対レベル→def/耐性スカラ）→ kill-turnゲート再判定（延期中・KILL_TURN_DESIGN §7）。
4. 確定した較正は `DMG`/`CHAR_REGISTRY` へ宣言的に実装し、CALIBRATION_ANALYSIS.md の Cx を更新。sim03/README に1ページ要約。

## 4. 改善提案の裁定（2026-07-13 ユーザー承認）

- **P1 採用**: `data/configA.json` は探索キャッシュexportをそのまま兼用（dispAtk同梱）。不足メタは trialXX.md 冒頭メタヘッダで補完。
- **P2 採用**: trialXX.md は1試行=1ファイル・連番（モードはメタヘッダで区別）。config JSONも configA.json 形式で分離。
- **P3 採用**: quantitative は「手法・スクリプト参照・入力データ」の明記を必須化（§3.4-1に反映済み）。
- **P4 第2走へ延期**: crit-off（config B）はフィンブルヴェトルでは装備DG非現実的のため実施しない。
  第2走で**より弱い反復ボス（中立属性推奨＝急所も同時に切れる）**を選定し、2×2の残り3セルをそこで埋める。
