## 2. 整合検証: パネル% × 1.8 = GEAR（全10枠一致・検証済み 2026-07-16）

configB の `GEAR` はパネル%の**一様×1.8**（＝幻獣加護スケール・configAと同一）で完全に説明できる:

| GEAR枠 | パネル% ×1.8 | configB 値 | 一致 |

| abi_cap | 55.0→99.0% | 0.99 | ✅ |
| burst_dmg | 290.0→522.0% | 5.22 | ✅ |
| burst_cap | 112.0→201.6% | 2.016 | ✅ |
| crit_rate | 22.5→40.5% | 0.405 | ✅ |
| acute | 8.0→14.4% | 0.144 | ✅ |

- `dmgup=0.09`（与ダメUP9%）は configA と同値・パネル対応行なし＝別ソース（幻獣/LB等・×1.8対象外）。`elem`/`spec`/`other`=0 はパネル該当区分なしと整合。
- HPUP 116%・三段攻撃確率UP 6% は非モデル化項目（生存/連撃系＝参考記録・C29関連）。
- **含意**: パネルとGEARの突合が取れた＝C26型「UI設定忘れ」はこのconfigでは無し（sim04/README §2-2 ゲート充足）。
- **較正上の注記**: `burst_dmg=5.22` は単独で+500%（C34の実機cap）超え＝**C34修正後は装備だけで恒常飽和**する水準。`abi_dmg=2.52` はC31（加算化）の影響を大きく受ける（M2の判別感度は十分）。
