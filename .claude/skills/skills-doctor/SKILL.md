# skills-doctor

## いつ使うか

- **スキルを足した / SKILL.md や実体を直した**とき（締める前に必ず）
- **golden 期待値・`test:t1` の閾値・T1 ベースラインを触った**とき
- 久しぶりのセッションで、スキル群がまだ機能しているか確かめたいとき

## 手順

```bash
node tools/skills/skill_doctor.mjs            # 全点検（負のテスト＋スモーク込み・約20秒）
node tools/skills/skill_doctor.mjs --quick    # 整合・予算・根拠・関門・必要性だけ（1秒未満）
node tools/skills/negative_tests.mjs --keep   # 発火しない検査を調べる（サンドボックスを残す）
```

見る7項目:

| 区分 | 何を見るか | 落ちたときの意味 |
|---|---|---|
| **[A] 5点整合** | `SKILL.md` ⇄ 実体 ⇄ `package.json` ⇄ `tools/skills/README.md` ⇄ CLAUDE.md/tools/README.md | 登録漏れ＝**その入口だけ古い**状態。同一コミットで揃える（REPO_STANDARDS §5-1） |
| **[B] description 予算** | 1本 ≤300字 / 合計 ≤1200字 | description は**全セッションの起動時に読まれる**＝恒常コスト。手順は本文へ |
| **[C] 検査の根拠** | 検査 id の `doc:` が指す規定 md と § が実在するか | **規定より先にツールが走った**状態。規定を先に更新する（ツールは写し・正ではない） |
| **[D] 関門の緩み** | golden 期待値・t1 [16-15]・T1 ベースラインが緩む方向へ動いていないか | 閾値を緩めた瞬間に回帰の意味が消える。**締める方向にだけ**動かす |
| **[E] 必要性** | 最終実行日と定義の最終更新日 | 90日超で棚卸し候補。使われないスキルは**消す**（増やすほど更新漏れの源） |
| **[F] 発火確認** | `negative_tests.mjs`（13ケース）＝わざと壊して検査が鳴るか | 鳴らない検査は**今この瞬間も素通り**している。緑に意味が無い |
| **[G] スモーク** | 各実体が副作用の無い引数で起動して正常終了するか | 実体が壊れている＝スキルは使えない |

## 判断（ツールはここまで踏み込まない）

- **[D] で golden が動いた** → 「意図した再fit か」を先に切り分ける。意図したなら
  `tools/search_calibrate.mjs` で再fit →「検証方法」表・override・`ENGINE_VERSION` を同一コミットで更新 →
  根拠を `CALIBRATION_ANALYSIS.md` の Cx へ → **`--update-guardrails --reason "<Cx>"`** で台帳を更新。
  ⚠ **期待値を実測に合わせて書き換えるのは再fit ではない**。
- **[D] で関門が緩んだ** → 原則は却下。フィクスチャを作り直した等の正当な理由があるときだけ、
  実測へ**締め直した**うえで `--update-guardrails --reason` に理由を残す。
- **[E] で未使用が出た** → 「出番が来ていないだけ」か「手順が変わって使われなくなった」かを見極める。
  後者は削除が正解（スキルは資産ではなく維持コスト）。
- **スキルを新設したくなったら**: 同じ手順を**手で3回**やってからにする。1回目は手でやる、2回目はメモ、3回目でスキル。

## 検査を足すときの順序（★これ自体が規律）

1. **規定を先に更新**（`ENGINE_INVARIANTS.md` / `REPO_STANDARDS.md`）— [C] がこの順序を機械で見張る。
2. 実体へ検査を足す。`doc:` に規定の節を書く。
3. **`negative_tests.mjs` にケースを足す**（わざと壊して鳴ることを確認）。ケースが無い検査は「あるだけ」で信用しない。
4. クリーン状態で違反ゼロを確認（誤検出のある検査は使われなくなる）。
5. `tools/skills/README.md` の一覧と本 SKILL.md の表を同一コミットで更新。

⚠ 負のテストのサンドボックスは `SKILL_ROOT` で切り替える＝**本物のリポジトリは壊さない**。
⚠ 文字列リテラルを見る検査で `stripJs`（文字列も潰す）を使うと**黙って空振り**する。`stripComments` を使う。
