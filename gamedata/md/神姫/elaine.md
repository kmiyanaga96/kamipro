# エレイン[契晶] #

## 1. 一次情報 (Claude Code編集不可) ##

### §1.1 基本スペック ####

- 神姫名: エレイン[契晶]
- 属性: 光
- 得意武器: 剣・特殊剣
- タイプ: バランス
- Lv1ATK: 2100
- Lv1HP: 364
- Lv80ATK: 10500
- Lv80HP: 1820

### §1.2 バースト/アビリティ ###

- バースト - **アカシック・セイヴァー**
  - **テキスト原文**: 光属性ダメージ(特大)/追加ダメージ※契晶を80個以上獲得している場合、3回発動
  - **バースト倍率**: 5.5 **バースト基礎値**: 3000
  - **有志検証データ**: 追加ダメージの倍率2倍、減衰30万。

- アビリティ1 - **アロンブレイク** (**赤**)
  - **テキスト原文**: 即座にゲージ消費なしでバーストを発動※契晶を4消費・同一ターン2回まで使用可能
  - **使用間隔/効果ターン**: 0T/なし
  - **効果対象**: 敵単体
  - **有志検証データ**: なし

- アビリティ2 - **レジェンドトラベラー** (**黄**)
  - **テキスト原文**: 自分と英霊の闇属性耐性・急所攻撃確率・バーストゲージUP・防壁付与(累積可)/英霊のバーストゲージが100以上の場合全体化※契晶獲得数に応じて同一ターンに複数回使用可能(最大6回)
  - **使用間隔/効果ターン**: 0T/3T
  - **効果対象**: 自分と英霊、または味方全体
  - **有志検証データ**: 闇属性耐性+3%、急所倍率1.05倍(発動率10%)、バーストゲージ+10、防壁500。全体化の判定はアビリティ使用時の英霊のゲージ量を参照。発動可能回数は契晶の獲得数によって変化。1～25：2 26～50：3回 51～70：4回 71～79：5回 80～：6回。

- アビリティ3 - **ナイツサプレス** (**青**)
  - **テキスト原文**: 敵全体のバースト攻撃耐性DOWN(専用/必中)/英霊のバーストゲージが100以上の場合、与ダメージDOWN(20%/専用/必中)追加※契晶を3消費・同一ターン1回まで使用可能
  - **使用間隔/効果ターン**: 0T/2T
  - **効果対象**: 敵全体
  - **有志検証データ**: バースト攻撃耐性-20%。与ダメージDOWNは他と併用不可。

- アビリティ4 - **PactCore[エレイン]** (**白**)
  - **テキスト原文**: 英霊のアビリティ再使用間隔1T短縮・攻撃ダメージ・バーストゲージUP/英霊のバーストゲージが100以上の場合、味方全体のバーストゲージ100UP・HP・状態異常を3つ回復※契晶を12消費
  - **使用間隔/効果ターン**: 0T/1T
  - **効果対象**: 英霊、または英霊と味方全体
  - **有志検証データ**: 攻撃ダメージUPの内訳: 通常攻撃+200%、バースト・アビダメに対して+100%。バーストゲージ+50。後半のバーストゲージ100以上の場合の効果は上記のバーストゲージ+50の効果で100以上になった場合でも発動。回復量は最大HPの30%、上限4900。

- アシスト1 - **グリフ・エレイン**
  - **テキスト原文**: 「契晶」を4つ付与/4の倍数回目のターン終了時「契晶」を5つ付与/光属性キャラがバースト攻撃する度「契晶」を1つ付与/英霊がバースト攻撃する度「契晶」を2つ付与
  - **有志検証データ**: 契晶の最大値は15。光属性の英霊がバーストを発動したときは3つ付与される。

- アシスト2 - **デバイス・エンブレム**
  - **テキスト原文**: 獲得した「契晶」の数に応じて味方全体に様々な強化効果付与※契晶を80個以上獲得している場合、ターン終了時英霊のHP・状態異常を1つ回復・バーストゲージUP
  - **有志検証データ**: 累計契晶数による効果は次の通り。10個以上: 攻撃+20%、30個以上: 防御+20%、50個以上:被ダメージカット10%、70個以上: 旺盛(基礎値42、最大約1.3552倍)、80個以上:特殊攻撃+20%。回復量は最大HPの30%、上限2900。バーストゲージ+20。

- アシスト3 - **ARRIVE[エレイン]**
  - **テキスト原文**: パーティ全体が光属性キャラの場合、味方全体にバースト性能UP・旺靭・会心・バーストダメージプラス付与・英霊に不屈(1回)・バーストゲージ100UP◆サブメンバー時にも発動
  - **有志検証データ**: バーストダメージ+20%、バーストダメージ上限+10%(エクシードなどと同枠)、バーストダメージプラス50万、会心発動率20%。それぞれのバフとして付与される(全て消去不可、他と併用可能)。



## 2. シムデータ (Claude Code編集可) ##

### §2.1 各データのシム内呼称 ###

- **アロンブレイク**: `alone`（同ターンカウンタ `T.alone`・ifishant加枠 `T.ifAlone`）
- **レジェンドトラベラー**: `legend`（バフキー `legend`・閾値バフ `leg_aslt`/`leg_vigor`/`leg_spec`・回数上限関数 `legendCap`）
- **ナイツサプレス**: `knights`（デバフキー `nights`）
- **PactCore[エレイン]**: `pactcore`（同ターンカウンタ `T.pactcoreN`）
- **グリフ・エレイン**: エンジン共通の契晶経済（`Sim.grif`/`keigyo`/`cum`・キャラキーなし）
- **デバイス・エンブレム**: 契晶閾値バフ（`leg_aslt` 等＝legend押下時に反映）＋ 80以上の英霊BG+20（`def.turnEnd`）
- **ARRIVE[エレイン]**: `def.burstPartyPassive`（`burst_dmg_arrive`/`bplus_arrive`）＋ `crit_rate_arrive`（バフキーなし・永続）

### §2.2 シム判明データ ###

> 出所: `gamedata/js/characters.js`（`elaine` エントリ）＋ `src/constants.js`（`DMG`/`BG`）に現在エンコード済みの値・挙動を配置（新規導出はしない）。

#### 基本 ####

- 定義キー: `elaine`（`type:'kamihime'` / `elem:'light'` / `gcls:'gl'`）
- `baseAtk`/`baseHp`: 10500 / 1820
- バースト係数: `burst_coef_a=5.5` / `burst_coef_b=3000`（スクショ確定）
- 得意武器: 剣・特殊剣 / `keigyoGain=1` / `gmax=100`
- 全アビ CD=0（実機CD1相当をターン内クォータguardで表現・C20/C21）＋契晶コスト: alone=4 / knights=3 / pactcore=12

#### バースト（アカシック・セイヴァー・`def.onBurst`） ####

- 追加ダメージ（アビ枠）: `elaine_burst_extra_mult=2` / `elaine_burst_extra_cap=800000`（⚠一次情報の減衰30万に対しシムは80万）
- 常時1回・契晶累計 `cum>=80` で3回発動（実機確定）

#### アロンブレイク（`alone`・赤） ####

- 定義: `['r', 0, 4]`（CD0・契晶4消費）・静的スコア `s=40`・`burstTrigger`
- 同ターン2回まで（`T.alone<2`）＋ifishant条件付き+1（C21: 押下時点でクォータ消化済みの場合のみ `T.ifAlone`）
- 効果: ゲージ消費なしでバースト

#### レジェンドトラベラー（`legend`・黄） ####

- 定義: `['y', 0, 0]`・静的スコア `s=120`
- ターン内回数上限 `legendCap(sim)`: 契晶累計 `cum` の閾値 [1, 26, 51, 71, 80] で 2〜6回（＋`T.ifLegend`）
- `legend` バフ（`dur_legend=3`・累積可）: 急所 `acute_legend=0.005`/stack（発動率10%×(1.05−1)）
- バーストゲージ: 英霊ゲージ100以上なら味方全体、未満なら[英霊, エレイン]に `BG.legend=+10`（全体化判定は押下時点の英霊ゲージ・実機一致）
- 契晶閾値のアシストバフ（デバイス・エンブレム由来）を押下時に反映（refresh単発・dur3）:
  - `cum>=10`: `leg_aslt`＝アサルト `assault_legend=+0.20`
  - `cum>=70`: `leg_vigor`＝旺盛 `vigor_legend=+0.3552`（基礎値42）
  - `cum>=80`: `leg_spec`＝特殊攻撃 `spec_legend=+0.20`
- ※闇属性耐性・防壁500は現状シム未モデル化

#### ナイツサプレス（`knights`・青） ####

- 定義: `['b', 0, 3]`（契晶3消費）・静的スコア `s=85`
- `nights` 付与: バーストダメージ `burst_dmg_nights=+0.20`（敵バースト耐性-20%の等価表現）・`dur_nights=2`・**非累積refresh**（C11・guardで有効中は再発動しない）
- ifishant枠での再発動（`T.ifKnights`）はnights有効中でも許可（refresh・アビ計数/契晶消費のみ・C21-A2）
- ※与ダメージDOWN追加（英霊ゲージ100以上時）は現状シム未モデル化

#### PactCore[エレイン]（`pactcore`・白） ####

- 定義: `['w', 0, 12]`（契晶12消費）・動的スコア `s`: 英霊のCD中アビ数 n≥3→150 / 2→110 / 1→70 / 0→20
- guard: 同ターン1回（`T.pactcoreN`＋`T.ifPactcore`）かつ英霊ゲージ100以上かつ英霊アビにCD中あり
- 効果: 英霊のCD中アビすべて−1 ＋ 味方全体ゲージ+100（`BG.pactcore=100`）
- ※一次情報の攻撃ダメージUP（通常+200%/バースト・アビ+100%）・英霊BG+50・HP/状態異常回復は現状シム未モデル化（ゲージ効果は「押下条件g≥100＋全体+100」へ単純化）

#### グリフ・エレイン（1アシ・エンジン共通実装） ####

- 契晶経済は `Sim` 本体に実装: 初期値 `keigyo=4`/`cum=4`（開始時4付与）・バースト毎 `grif(owner)`＝`keigyoGain`（神姫1 / 英霊3=光英霊）・4の倍数ターン終了時+5・保有上限 `KEIGYO_MAX=15`（累計 `cum` は無上限）

#### デバイス・エンブレム（2アシ） ####

- 契晶閾値バフ（10+/70+/80+）は上記のとおり **legend押下時に反映**（実機は常時アシスト発動・シムはlegend経由の近似）
- `cum>=80`: ターン終了時に英霊ゲージ+20（エレイン `def.turnEnd`＝`addG([LEADER],20)`。2026-07-19 にエジソンdefからの誤配置を移管＝英霊がエジソン以外でも発動）
- ※防御+20%(30+)・被ダメージカット10%(50+)・英霊HP/状態異常回復は現状シム未モデル化

#### ARRIVE[エレイン]（3アシ・`def.burstPartyPassive`） ####

- 全員光属性編成のとき全バーストへ: バーストダメージ `burst_dmg_arrive=+0.20` ＋ バーストダメージプラス `bplus_arrive=343000`（減衰外フラット。⚠一次情報の50万に対しシムは34.3万）
- 会心発動率 `crit_rate_arrive=+0.20`（`_na()` に常時反映・永続）
- ※バーストダメージ上限+10%・旺靭・不屈・英霊BG100は現状シム未モデル化
