### §1.2 バースト/アビリティ ###

- バースト - **メテオ・ダイブ**
  - **テキスト原文**: 光属性ダメージ(極大)/追加ダメージ※天真爛漫の場合、効果量1.5倍
  - **バースト倍率**: 5.5 **バースト基礎値**: 3000
  - **有志検証データ**: ダメージ倍率2倍、減衰40万。1.5倍時はダメージ倍率3倍、減衰60万。

- アビリティ1 - **ロケットアサルト** (**赤**)
  - **テキスト原文**: 即座にゲージ消費なしでバーストを発動※天真爛漫の場合、同一ターン2回まで使用可能
  - **使用間隔/効果ターン**: 7T/なし
  - **効果対象**: 敵単体
  - **有志検証データ**: なし。

- アビリティ2 - **リーガルディフェンド** (**黄**)
  - **テキスト原文**: 自分に不屈付与/味方全体をかばう※全体攻撃を含む/HP25%以上の味方のHPを25%にする
  - **使用間隔/効果ターン**: 14T/1T
  - **効果対象**: 自分
  - **有志検証データ**: 不屈はターン制のため効果時間中は戦闘不能にならない。

- アビリティ3 - **ロイヤルサプレッション**（**青**）
  - **テキスト原文**: 敵全体の攻撃・防御DOWN(特大/必中)・味方全体のバーストゲージUP※天真爛漫の場合、与ダメージDOWN(30%/専用/必中)追加
  - **使用間隔/効果ターン**: 3T/180秒・1T
  - **効果対象**: 敵全体
  - **有志検証データ**: 攻防デバフはB枠で-30%、バーストゲージ+25。与ダメDOWNは他と併用不可(真化アルテミスのものと相互上書き)。攻防デバフが180秒、与ダメDOWNのみ1T。


- アビリティ4 - **LinkSkill[メタトロン]** (**黄**)
  - **テキスト原文**: 光属性キャラの特殊攻撃UP・バーストストリークダメージ大幅UP※自分のHPが25%以下の場合、攻撃ダメージUP追加・戦闘中1回のみ使用可能
  - **使用間隔/効果ターン**: 1T/2T
  - **効果対象**: 味方全体
  - **有志検証データ**: 特殊攻撃+30%、バーストストリークダメージ+30%。攻撃ダメージUPは通常攻撃に対して+200%、アビリティとバーストに対しては+100%。

- アシスト1 - **ピュアプログレス**
  - **テキスト原文**: 光属性キャラがバースト5回発動する度に、自分に真心付与・アビリティ再使用間隔1ターン短縮/真心を5個獲得以降、天真爛漫付与/自分がピンチの時、バースト性能大幅UP・忍耐・反逆
  - **有志検証データ**: 天真爛漫の効果は特殊攻撃+30%。バースト性能大幅UP時、バースト本体はダメージ倍率10倍、減衰200万に変化。追加ダメージは倍率はそのままで減衰80万に変化(1.5倍時は120万)  。忍耐最大値1300(固定値0)  、反逆最大値50  。バフアイコンは付与されない。

- アシスト2 - **AnotherLink[メタトロン]**
  - **テキスト原文**: パーティ全体が光属性キャラの場合、全攻撃性能UP・最終ダメージUP◆サブメンバー時にも発動
  - **有志検証データ**: 通常攻撃ダメージ+20%、通常攻撃ダメージ上限+10%、バーストダメージ+20%、バーストダメージ上限+10%、アビリティダメージ+20%、アビリティダメージ上限+10%、最終ダメージ+10%。

### §2.2 シム判明データ ###

> **⚠ 運用前提（ユーザー提供のプレイヤー集合知・2026-07-31）**: メタトロンは **アルテミスとともにサブに編成して火力を底上げするのがセオリー**。
> ∴ **本シムで意味を持つのは アシスト2 AnotherLink（`subAssists`）のみ**であり、**アビリティ詳細の実装は凍結**する（§3.2 参照）。
> 以下のアビリティ記述は登録済みの内容の記録であって、**実機検証も較正も行わない**（メイン編成で使う判断が出たら解凍する）。

**基本値**: `baseAtk: 14900` / `baseHp: 3050`（Lv80 値）／`elem:'light'`／`favWeapon:['銃','ハンマー']`／`gcls:'gmt'`／`keigyoGain: 1`／`gmax: 100`。

**バースト メテオ・ダイブ**
- 係数 `burst_coef_a: 5.5` / `burst_coef_b: 3000`（一次情報のまま。アルテミス[神想真化]と同値）
- 追加ダメージ＝`def.onBurst` でアビ枠 `_decay('abi', _na()*倍率, 減衰)`。
  通常時 `metatron_extra_mult: 2` / `metatron_extra_cap: 400000`、
  **天真爛漫時** `metatron_extra_mult_tenshin: 3` / `metatron_extra_cap_tenshin: 600000`（＝一次情報「効果量1.5倍」の有志検証値をそのまま2系統で持つ）

**1アビ ロケットアサルト（`rocket` / `rocket_re`・赤・CD7）**
- ゲージ消費なしでバースト発動（`sim.burst()`）。アリアン `elegant` と同型。
- **同一ターン2回目は別キー `rocket_re`（CD0＋guard）で表現**。⚠ `rocket` 本体は押下時に CD7 を張るため、
  同一キーでは同ターン再押下が**構造的に不可能**（`_candidates` が `cd!==0` を除外する）。
- `rocket_re` の guard: `T.rocket===1 && metatron_magokoro >= 5`（＝天真爛漫のときのみ）。再発動は赤アビとして計数（`_countAbilityUse`）。

**3アビ ロイヤルサプレッション（`royal`・青・CD3）**
- **防御DOWN -30%**（`defdown_metatron`・B枠・必中）を `buf.metatron_def` で表現。`_na()` の `defdown` 合算（上限50%）に参加。
  **非累積（presence 判定）**＝CD3 で撃ち直しても重ならない（B枠の名前付き枠のため）。`DEBUFF_KEYS` に登録済み＝`buffCount`(C38) には計上しない。
- **味方全体バーストゲージ +25**（`bg_metatron_royal`・`addG(CHARS, 25)`）。
- **未モデル化**: 攻撃DOWN（敵の攻撃力＝生存側）・与ダメージDOWN 30%（同上）。

**4アビ LinkSkill[メタトロン]（`metalink`・黄・CD1・戦闘中1回）**
- 光属性キャラの**特殊攻撃 +30%**（`spec_metatron_link`・`buf.metatron_spec`・2T）→ `_na()` の特殊攻撃枠へ加算。
- **バーストストリークダメージ +30%**（`streak_metatron_link`・`buf.metatron_streak`・2T）→ `_attackPhase` の `sdup` へ加算（マナポライトと同枠合成）。
- 戦闘中1回は state `metatron_link_used` の guard（アルテミス `linkskill` と同型）。
- **未モデル化**: 「自分のHP25%以下なら攻撃ダメージUP追加」（通常+200% / アビ・バースト+100%）＝**HP 状態を持たないため発動しない**。

**アシスト1 ピュアプログレス（`def.onPartyBurst`）**
- 光属性キャラのバースト **5回ごと**（`metatron_magokoro_per`）に 真心 +1 ＆ **自分の全アビCD -1**。
- 真心 **5個以降**（`metatron_tenshin_at`）で **天真爛漫**＝①特殊攻撃 +30%（`spec_tenshin`・**自分のみ**）②バースト追加ダメージ 1.5倍 ③`rocket_re` 解禁。
- **バフアイコン非付与**の一次情報に合わせ、`buf` ではなく **state** で保持（＝`buffCount` に乗らない）。
- **未モデル化**: 「自分がピンチの時、バースト性能大幅UP・忍耐・反逆」（バースト本体 倍率10倍/減衰200万、追加ダメージ減衰80万[1.5倍時120万]、忍耐1300、反逆50）
  ＝**ピンチ＝低HP状態がシムに存在しない**ため発動しない。⚠ **これは本キャラの最大火力ルートである可能性が高い**（A2/A3）。

**アシスト2 AnotherLink[メタトロン]（`subAssists`）**
- パーティ全体が光属性のとき、**サブメンバー時にも発動**。`buildFormation` が集約して `DMG.sub_*` へ代入（`allLight` 判定つき）。
- 通常攻撃ダメージ +20%（`sub_na_dmg`）／通常上限 +10%（`sub_na_cap`）／バーストダメージ +20%（`sub_burst_dmg`）／バースト上限 +10%（`sub_burst_cap`）
  ／アビリティダメージ +20%（`sub_abi_dmg`）／アビリティ上限 +10%（`sub_abi_cap`）／**最終ダメージ +10%**（`final_dmg`）。
- ⚠ **`sub_na_dmg` の効き所は限定的**: シムは通常攻撃のダメージを積まないため、通常攻撃ダメージUPが乗るのは
  **ジャッジメント ph2（通常攻撃フェーズ）のみ**。一方 **`sub_na_cap` は `_naForAbi` の cap に効く＝アビ全般へ波及**する。
- ⚠ **複数キャラの AnotherLink は `Math.max`（非累積）で合成**している（アルテミスと同時編成時に効く）。実機の重複規則は**未検証＝A7**。

**2アビ リーガルディフェンド＝`abilities` に登録していない**
- 不屈／かばう／味方のHPを25%にする＝**すべて生存側**で与ダメージに無関与。
- 押せる候補として登録すると、探索が効果ゼロの手に手数を使うだけなので**あえて登録しない**。
- ⚠ ただし実機では「HPを25%にする」→ ピンチ → アシスト1 のバースト性能大幅UP、という**能動的コンボの起点**である可能性が高い（A2）。

### §3.4 `反逆` 編成というアーキタイプ（スコープ外・2026-07-31 ユーザー提供） ###

- 本シムが前提とする **`旺盛`（ヴィゴラス）＝フルHP維持**の編成に対し、**意図的に低HPを維持する `反逆`（リベリオン）編成**が実機に存在する。
  ヴィゴラスの代わりにリベリオンを多く採用し、**自傷ダメージなどで能動的にHPを減らす**キャラで固める構成。
- **メタトロンはこのアーキタイプの一員**＝2アビ「味方のHPを25%にする」・アシスト1「ピンチ時バースト性能大幅UP」・
  4アビ「HP25%以下で攻撃ダメージUP」は、いずれも `反逆` 編成でこそ機能する設計。
- **⚠ 現時点で本シムが考察する必要は皆無**（ユーザー判断）。理由: ①メタトロンはサブ運用が前提 ②較正ボスのロキはノーダメージ討伐＝
  フルHP前提が厳密に成立する ③`反逆` を扱うには HP を状態として持つ必要があり、ROADMAP 未確定Phase(i)「敵行動・味方生存」の領域。
- ∴ **A2/A3 はクローズ**。将来 `反逆` 編成を扱う判断が出たときに、本節を起点に再開する。
