## P2-4（重複除去）🔶 測定器が完成・L はこれから（v0.14.0・2026-08-15）

★**問いを変えた**。P2-2 は「変わったか」を問うて失敗した（画面が常時動くので「変わっていないフレーム」が無い）。
P2-4 は **「取りこぼさないと保証できる最大の間引きはどれか」**を問う。

⭐ **等間隔の間引きには証明がある**＝s フレームおきに採れば、**s フレーム以上出続けるものは必ず1回捕まる**
（任意の連続 s フレームの窓に採用が1枚入るため）。賢い検出器はこの保証を持たない。
**検出が信用できない場面では、鈍いが証明のある方法を採る。**

⚠⚠ **保証は `s ≦ ポップアップ寿命 L` のときだけ**。そして **L は未測定**（＝**発見⑧**・
「入れ替わりが 33ms 級かもしれない」）。**L が 1〜2 なら間引きは一切できない**＝
**出口条件に間引きでは到達できない**という結論もありうる。

∴ **測定を先に出し、間引きは測定が許した分しかしない**形にした:

- **`stride` は未較正（null）＝現状は間引かない**。落とすのは**完全重複だけ**（＝情報損失ゼロ）。
  ★**推測で埋めない**＝「読めないときは読めないと言う」の間引き版。
- ★**寿命の測定器を3つ作って2つ捨てた**（すべて出荷前に既知の正解で反証）:
  ①ROI 全体のラグ距離の膝 → **背景の動きと混ざる**（撤去した `persistenceRatio` と同じ構造の誤り・3度目）
  ②セル単位「次の jump までの長さ」 → **真の L が 10/6/3 のすべてで 3 を返した**
  ③✅ **セル単位「jump 直後に |Δ|=0 で凍る長さ」（長さ1は除く）** → **真値 10/6/3 を J によらず厳密に復元**
  ★③が効くのは計画の文言どおり「**ポップアップは静止**」だから。**長さ1を除くのは定義**（凍っていない）で
  調整つまみではない。⚠ 実走を模した汚染（**静止セル38%＋途中切替**）でも壊れないことを確認済み。
- ⭐ **受入条件＝3つの J での一致**（`lifetimeFrames` は一致時のみ値が入る）。**両方向を検証済み**＝
  L が実在すれば完全一致、実在しない場面（真 L=1・汚染あり）では **13/13/21 と食い違う**。
- **`eventContrast`**（ラグ1 の p90/p50）が「離散的な出来事があるか」の検査。合成 **あり 6.2〜6.3 / なし 1.02〜1.03**、
  **実走 6.731＝出来事は実在する**。⚠ 初版 `persistenceRatio` は**ポップアップゼロの背景で 0.537**＝誤導したので撤去。
  ★**ラグ曲線の低い側は背景の床で、信号は上側にしか出ない**。反証は回帰に固定した。

⭐ **回帰フィクスチャを実走の距離分布に合わせた**＝合成の隣接フレーム距離を
**実走の p50 6.72 / p90 40.34 / p99 112.63 に一致させた**（実測 6.70 / 41.7 / 110）。
∴ 合成が **P2-2 を実際に失敗させた動きを持つ**（「変化検出は出口条件を満たせない」ことをテストで固定）。

⚠ **テストを書いて主張が1つ修正された**: 「stride=L/2 なら全部捕まる」は**偽**。
正しくは**「寿命が stride 以上あるものは必ず捕まる」**（末尾で切れた3フレームのポップアップで実際に落ちた）。

### 経緯（v0.11.0 → v0.12.0）

**v0.11.0 の生プロファイル持ち帰りが効いて、推測なしで原因が確定した**。
★真因は閾値の高さではなく**「右端の探し方」**＝`閾値を超えた最後の列` は**塗りの連続性を見ていない**。
実測では真の境界（idx 105）より右に**孤立した 1〜2 列**が立つことがあり、それだけで右端が末尾へ飛んでいた。

**違反は1種類ではなく2種類だった**:

| 型 | 割合 | 中身 | 対処 |
|---|---|---|---|
| **孤立列** | 9/10 | 末尾 1〜2 列だけ 0.11〜0.31（間は厳密に 0） | 右端を**2区間の階段フィット**へ＝**閾値パラメータを廃止** |
| **ROI 汚染** | 1/10 | 平坦部 0.2083（正常 0.375〜0.4583）／中央と末尾に**占有率 1.0 のブロック**＝赤い演出が覆う | **読めないと言う**（旧実装は「HP 100%」と報告していた） |

- 階段フィットは **`peak` にも塗り水準（0.375〜0.86）にも依存しない**＝演出で peak が 1.0 に化けても動かない。
- ⚠ **代償**: **満タンのバーも「読めない」になる**（空の区間が無いと汚染と区別できない）。
  取りこぼすのは戦闘開始前の 100% 区間だけ＝許容。理由は `skipCauses`（`flash` / `noEmptyRegion`）で出る。
- ⭐ **回帰の作り方を変えた**＝`tools/fixtures/t1_hp_profiles_M3-1.json` に**実走のプロファイルを現物のまま**収録
  （画像ではなく 120個の集計値＝§10.3 に非抵触）。**旧実装ならこのプロファイルで 1.0 に跳ぶ**ことまで固定した。
- ⏳ **実走での再確認は次の走査**（設計上ゼロだが実測していない）。**CT ドット抽出は未着手**。
